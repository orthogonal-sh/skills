# Task Tracker

Use when the user asks what is on their plate, wants a daily standup, or needs ongoing task state carried across sessions.

## Suggested Workflow

- Read existing task state before adding or changing anything.
- Separate today, upcoming, blocked, and waiting tasks.
- Keep updates concrete and timestamped.
- Distill long-running patterns into durable memory only when useful.

## Candidate Sources

- OpenClaw `task-tracker`
- Local task files, issue trackers, and calendar-derived commitments
