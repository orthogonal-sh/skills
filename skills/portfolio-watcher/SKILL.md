# Portfolio Watcher

Use this skill when tracking a set of assets over time.

## Workflow

- Clarify tickers, quantities, cost basis, alert thresholds, and reporting cadence.
- Fetch current prices, daily moves, relevant news, dividends, splits, and filings.
- Highlight material changes, concentration, correlation, and unresolved data issues.
- Keep conclusions informational and avoid personalized investment advice.
