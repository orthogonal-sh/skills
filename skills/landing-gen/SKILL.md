# Landing Gen

Use this skill when generating a simple landing page for a package, product, project, or repo.

## Workflow

- Gather the product name, audience, value proposition, setup path, and proof points.
- Create a usable first screen and focused supporting sections.
- Keep implementation consistent with the target stack and existing design conventions.
- Verify responsive layout, text fit, links, and core interactions.
