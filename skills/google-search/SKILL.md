# Google Search

Use this skill when a task involves Google-style search discovery, query refinement, source finding, or current web research.

## Workflow

- Clarify the exact information need, recency window, location, and source constraints.
- Build targeted queries with operators when useful and avoid over-relying on snippets.
- Open and compare primary or authoritative sources before summarizing.
- Cite important claims and explain remaining uncertainty when sources disagree.
