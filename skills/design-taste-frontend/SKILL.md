# Design Taste Frontend

Use this skill when a frontend works technically but feels generic, cluttered, or visually weak.

## Principles

- Start from the product's job and audience.
- Remove unnecessary decoration before adding new styling.
- Use alignment, spacing, type scale, and contrast to create hierarchy.
- Avoid one-note palettes and oversized marketing patterns in work tools.
- Check the actual rendered result, not just the code.
