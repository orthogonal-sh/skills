# Homey CLI

Use this skill when a task involves Homey smart-home devices, apps, flows, zones, automation debugging, or command-line/API management.

## Workflow

- Identify the Homey account, hub, app, device, flow, and whether actions are read-only or will affect the home.
- Inspect current devices, zones, capabilities, flow triggers, and recent errors before changing automations.
- Prefer small reversible changes and avoid surprising device actions without explicit approval.
- Verify by checking flow status, device state, logs, and any expected physical-world outcome.
