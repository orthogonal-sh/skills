# First Principles Decomposer

Use this skill when the user wants to reason from basics instead of copying conventional solutions.

## Workflow

1. Name the problem and desired outcome.
2. List known facts, constraints, and assumptions.
3. Challenge assumptions that are inherited rather than necessary.
4. Rebuild options from the irreducible facts.
5. Choose the simplest next test.

## Output

- Facts.
- Assumptions.
- Constraints.
- Options.
- Next experiment.
