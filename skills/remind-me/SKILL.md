# Remind Me

Use this skill when the user asks to be reminded later, wants a recurring nudge, or needs reminder state checked.

## Workflow

- Clarify ambiguous dates, timezones, recurrence, and destination before scheduling.
- Prefer native reminder or cron tooling already configured for the agent.
- Include enough context in the reminder payload for future-you to act without rereading the full conversation.
- Confirm the exact scheduled time and recurrence in plain language.
- Inspect existing reminders before changing or deleting them.
