# Schema Gen

Use this skill when structured data needs a clear contract.

## Workflow

- Identify producers, consumers, required fields, optional fields, and versioning needs.
- Choose the schema format already used by the project.
- Encode validation rules, examples, defaults, nullability, and error expectations.
- Check backward compatibility before changing existing contracts.
- Add focused tests or sample payloads that exercise valid and invalid data.
