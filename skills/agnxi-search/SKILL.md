# Agnxi Search

Use this skill for exploratory web research where the user needs multiple candidate sources, entities, or references quickly.

## Workflow

1. Convert the question into focused search queries and entity variants.
2. Gather diverse sources instead of relying on a single result page.
3. Filter for recency, authority, primary sources, and corroboration.
4. Return the answer with links, caveats, and useful next searches.

## Notes

- Be explicit when information is uncertain or source quality is weak.
- For high-stakes topics, verify with primary sources.
