# Computer Use

Use this skill when controlling a graphical interface on behalf of the user.

## Workflow

- Inspect the current screen before acting and identify the target state.
- Use small, reversible steps with verification after each important action.
- Avoid destructive or external actions unless the user has clearly authorized them.
- Recover from stale screens, dialogs, failed clicks, or unexpected navigation by re-inspecting.
- Summarize what changed and any remaining manual confirmation needed.
