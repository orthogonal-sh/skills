# glab

Use this skill when working with GitLab through the `glab` command-line tool.

## Capabilities

- Inspect and manage issues, merge requests, branches, and releases.
- Read pipeline status, jobs, and CI logs.
- Create comments, reviews, and merge request summaries.
- Query GitLab APIs with structured command output.
