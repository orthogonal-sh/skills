# wacli

Use this skill when a task involves WhatsApp chat search, message summaries, media lookup, drafting replies, or WhatsApp automation from a CLI.

## Workflow

- Identify the chat, participant, date range, media requirements, and whether the action is read-only.
- Ask for confirmation before sending messages, joining groups, deleting content, or changing chat state.
- Keep private chat context scoped to the requested task.
- Verify recipient, content, attachments, and delivery result for any confirmed outbound message.
