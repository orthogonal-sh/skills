# Code Reviewer

Use this skill when reviewing a diff, pull request, or proposed implementation.

## Workflow

- Understand the intended behavior and changed files before judging the code.
- Prioritize concrete bugs, regressions, missing tests, and security issues.
- Reference exact files and lines for each finding.
- Distinguish blocking issues from style suggestions.
- End with residual risk and any tests that still need to run.
