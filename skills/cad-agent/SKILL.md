# CAD Agent

Use this skill when a task involves CAD models, parametric design, geometry inspection, or manufacturing-ready exports.

## Capabilities

- Interpret design requirements into CAD-oriented steps.
- Inspect dimensions, constraints, and part relationships.
- Suggest model edits, export formats, and validation checks.
- Prepare instructions for CAD automation tools or scripts.
