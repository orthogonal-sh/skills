# Obsidian

Use this skill for work inside an Obsidian vault: notes, backlinks, tags, templates, daily notes, or knowledge cleanup.

## Workflow

- Identify the vault path and inspect local naming, frontmatter, and folder conventions.
- Search existing notes before creating duplicates.
- Preserve wiki links, embeds, tags, aliases, and backlinks.
- Keep edits narrow unless the user asked for a reorganization.
- Summarize created or changed notes with paths.
