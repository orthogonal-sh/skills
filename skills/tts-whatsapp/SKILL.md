# TTS WhatsApp

Use this skill when the user wants a WhatsApp voice message generated from text.

## Workflow

- Confirm the recipient, language, voice, and message text before sending.
- Generate concise speech that sounds natural when heard aloud.
- Create audio in a WhatsApp-compatible format and attach it to the message.
- Respect outbound messaging approval boundaries unless delivery is explicitly requested.
