# Parakeet STT

Use this skill when transcribing audio locally with Parakeet speech-to-text models.

## Workflow

- Confirm the audio file, language expectations, and output format.
- Run local transcription with model settings appropriate for the machine.
- Clean the transcript for readability without inventing missing words.
- Provide timestamps, speaker notes, or confidence caveats when available.
