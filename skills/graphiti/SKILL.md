# Graphiti

Use this skill when a task involves Graphiti-style temporal knowledge graphs, agent memory, entity extraction, relationship updates, or graph queries.

## Workflow

- Identify the source episodes, entities, time bounds, and questions the graph should answer.
- Normalize entities and relationships, preserving timestamps, provenance, and uncertainty.
- Avoid duplicating entities; merge or link records only when identity confidence is high.
- Verify graph updates with targeted queries and source-backed examples.
