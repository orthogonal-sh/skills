# Vercel React Best Practices

Use when writing, reviewing, or refactoring React or Next.js applications, especially around performance and rendering behavior.

## Suggested Checks

- Component boundaries, server/client split, and data fetching.
- Caching, streaming, bundle size, and image handling.
- Accessibility and interaction states.
- Avoid unnecessary abstractions and preserve existing app patterns.
