# Vercel React Best Practices

Use this skill when building or reviewing React apps intended for Vercel, especially Next.js projects.

## Checklist

- Follow the project's routing, rendering, and data-fetching patterns.
- Keep server and client boundaries explicit.
- Use caching, revalidation, and environment variables deliberately.
- Preserve accessibility and performance when adding components.
- Run lint, type checks, unit tests, and relevant integration tests before finishing.
