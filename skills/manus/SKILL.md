# Manus

Use this skill when the user wants to create, inspect, or manage tasks in Manus.

## Workflow

1. Translate the request into a concrete Manus task with deliverables and constraints.
2. Start the task only when external delegation is clearly intended.
3. Poll task status and retrieve artifacts or final answers.
4. Summarize results with links or IDs.

## Safety

- Ask before submitting tasks that may browse, contact others, spend money, or publish content.
- Keep task prompts free of unrelated private context.
