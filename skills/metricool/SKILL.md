# Metricool

Use this skill when the user wants to manage social publishing through Metricool.

## When To Use

- Schedule posts across supported social platforms.
- Inspect calendar slots or scheduled content.
- Draft campaign copy for Metricool review.
- Pull performance summaries.

## Workflow

1. Confirm platforms, account, timing, and copy.
2. Prepare the post text and media references.
3. Submit through the Metricool API or UI workflow.
4. Verify scheduled status.

## Safety

Posting is external. Get explicit approval before scheduling or publishing content.
