# ClipIt Media

Use this skill when the user wants advanced audio or video processing from a local file or URL.

## Workflow

1. Identify the source, output format, target timestamps, aspect ratio, captions, and platform constraints.
2. Inspect media duration, streams, codec, resolution, and audio layout.
3. Produce an edit plan and run the smallest necessary processing command.
4. Verify output duration, file size, playback, and captions.

## Safety

- Avoid overwriting original media.
- Respect copyright constraints and platform limits.
