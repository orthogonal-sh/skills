# Linkding

Discovery stub for a Linkding bookmark management skill.

Use when a user wants to save a link, search saved bookmarks, manage tags, archive pages, or build a lightweight personal web library.

## Candidate Capabilities

- Add bookmarks with title, notes, and tags.
- Search and filter saved bookmarks.
- Archive or update bookmark metadata.
- Return source URLs with short context.
