# Tmux Agents

Use this skill when a task involves tmux-based agent sessions, long-running terminal workflows, pane orchestration, or recovery after disconnects.

## Workflow

- Inspect existing sessions, windows, panes, commands, and logs before starting or interrupting agents.
- Use clear session/window names and avoid stealing interactive panes unexpectedly.
- Capture relevant output and state transitions for handoff.
- Verify that required processes are still running or cleanly stopped before finishing.
