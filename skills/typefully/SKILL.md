# Typefully

Use when a user wants help with Typefully drafts, scheduled posts, social threads, or cross-posting.

## Safety Rules

- Ask before publishing or scheduling posts.
- Confirm target accounts, post text, media, and timing.
- Respect platform-specific length and formatting limits.
- Prefer draft creation when approval is incomplete.
