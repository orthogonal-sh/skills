# ordercli

Use this skill when a task involves command-line ordering flows, menu lookup, cart management, checkout preparation, order tracking, or debugging an order automation.

## Workflow

- Identify the provider, account context, location, menu, and whether the task is read-only or may create an order.
- Inspect available menus, item options, cart contents, prices, fees, and fulfillment windows before acting.
- Treat payment, final checkout, delivery address changes, and external submissions as confirmation-required actions.
- Verify results with order IDs, totals, timestamps, and status responses where available.
