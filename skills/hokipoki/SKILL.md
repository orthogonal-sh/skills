# HokiPoki

Use this skill when the user wants to switch AI models, compare model behavior, or route tasks across local AI CLIs.

## Workflow

1. Check the available providers and current active model.
2. Pick the model based on task type, context needs, tool access, and cost.
3. Run a small test prompt when reliability matters.
4. Note the chosen model and why it fits.

## Safety

- Do not move secrets between providers.
- Avoid changing global defaults unless the user asked for it.
