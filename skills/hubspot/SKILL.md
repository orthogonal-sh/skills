# HubSpot

Use this skill when a task involves HubSpot CRM records, lists, deals, tickets, pipelines, properties, workflows, or enrichment.

## Workflow

- Identify the portal, object type, record IDs, property names, and whether changes should be previewed or applied.
- Search existing records first to avoid duplicates, then inspect associations and lifecycle context.
- Keep updates precise, auditable, and aligned with existing CRM property conventions.
- Summarize records found, fields changed, skipped records, and any data-quality concerns.
