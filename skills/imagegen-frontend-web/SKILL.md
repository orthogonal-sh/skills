# Imagegen Frontend Web

Use this skill when a frontend needs generated raster images rather than SVG or code-native graphics.

## Workflow

- Identify the role of the image, dimensions, aspect ratio, and art direction.
- Use real product or domain details in the prompt.
- Generate small variant sets and select the most usable asset.
- Optimize output for web size and format.
- Verify the image renders correctly in the final layout.
