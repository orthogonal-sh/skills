# Diagramming Processes

Use this skill when a process, architecture, data flow, queue, lifecycle, or decision path would be clearer as a diagram.

Choose the simplest useful diagram type, label actors and boundaries explicitly, keep flows directionally consistent, and pair the diagram with only the context needed to interpret it.
