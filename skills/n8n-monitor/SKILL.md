# n8n Monitor

Use this skill when checking operational health for n8n automations.

## Workflow

- Identify the workflows, schedules, credentials, and recent execution window.
- Review failures, retries, long-running jobs, disabled nodes, and rate-limit errors.
- Separate transient provider issues from workflow logic problems.
- Recommend fixes with workflow IDs, node names, and reproducible evidence.
- Verify that corrected workflows run successfully or are safely paused.
