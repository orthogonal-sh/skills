# Sysadmin Toolbox

Use when troubleshooting local or server issues involving networking, processes, disk space, services, logs, permissions, or performance.

## Suggested Workflow

- Inspect current state before changing configuration.
- Prefer read-only diagnostic commands first.
- Preserve existing config and make reversible changes.
- Summarize findings with exact commands and evidence.

## Candidate Sources

- OpenClaw `sysadmin-toolbox`
- Common Unix, macOS, Linux, and networking diagnostic tools
