# Obsidian Daily

Use when a user wants daily notes, journal entries, task logs, meeting notes, or dated knowledge captured in an Obsidian vault.

## Suggested Workflow

- Identify the vault and daily-note format.
- Append concrete entries rather than empty placeholders.
- Preserve existing note structure and headings.
- Use date-specific notes for logs and long-term memory only for distilled facts.

## Candidate Sources

- OpenClaw `obsidian-daily`
- `obsidian-cli` and Obsidian daily note conventions
