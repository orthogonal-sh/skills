# Mcporter Skill

Use this skill when the task involves MCP servers, tool discovery, auth, transport setup, or mcporter diagnostics.

## Workflow

- Inspect configured servers and transports before changing MCP config.
- Verify authentication, environment variables, and command paths.
- Prefer structured tool metadata over guessing schemas.
- Test calls with small, safe inputs first.
- Document server names, tools, and any config changes made.
