# Changelog Generator

Use this skill when creating changelogs, release notes, version summaries, or user-facing ship notes from repository history.

## Stub Scope

- Compare explicit refs, tags, or date ranges before summarizing changes.
- Group entries by added, changed, fixed, removed, security, and internal when useful.
- Rewrite commit noise into clear user-facing language.
