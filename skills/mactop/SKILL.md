# mactop

Use this skill when inspecting Apple Silicon system performance from the terminal with `mactop`.

## Capabilities

- Monitor CPU, GPU, neural engine, memory, power, and thermal signals.
- Capture before-and-after measurements for performance work.
- Identify throttling, high utilization, or runaway processes.
- Summarize terminal telemetry into concise diagnostics.
