# Animation Gen

Use this skill when a task involves creating or refining animation concepts, prompts, storyboards, motion graphics, or generated animation clips.

## Workflow

- Define subject, style, duration, aspect ratio, motion beats, target platform, and output format.
- Use references or storyboard frames when they reduce ambiguity.
- Check temporal consistency, framing, legibility, timing, and artifact risks.
- Export variants with clear filenames and review notes for iteration.
