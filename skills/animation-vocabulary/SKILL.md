# Animation Vocabulary

Use this skill when the user needs precise language for motion design.

## Workflow

- Identify the observed or desired motion behavior.
- Name the relevant animation concepts and explain them in practical terms.
- Translate vague requests into implementable timing, easing, and sequencing.
- Provide examples from UI, film, games, or motion graphics when helpful.
- Keep the vocabulary tied to decisions the user can act on.
