# Apple Contacts

Use this skill when the user wants help with local Apple Contacts, address books, deduplication, cleanup, or contact lookup.

## Workflow

1. Clarify whether the task is read-only, cleanup planning, export, or an approved modification.
2. Inspect contact data with the least invasive method available.
3. Identify duplicates, missing fields, stale organizations, and normalization issues.
4. Ask before writing changes that modify, merge, delete, or sync contacts.

## Notes

- Contacts are private personal data; avoid exposing details in shared contexts.
- Prefer reversible exports or backups before bulk edits.
