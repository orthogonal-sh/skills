# Sentry CLI

Use this skill when working with Sentry from the command line, especially releases, source maps, debug IDs, upload validation, deploy markers, project metadata, or CI integration.

Prefer Sentry CLI commands with explicit org and project scopes, verify auth before writes, and capture exact release identifiers, environment names, and uploaded artifact paths in the final report.
