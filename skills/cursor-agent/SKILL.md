# Cursor Agent

Use this skill when delegating or coordinating software engineering work through the Cursor CLI agent.

## Capabilities

- Start Cursor-agent tasks with clear scope and repository context.
- Monitor coding, review, refactor, and implementation workflows.
- Capture results, diffs, risks, and verification steps for handoff.
