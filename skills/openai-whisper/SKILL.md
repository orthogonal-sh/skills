# OpenAI Whisper

Use this skill when a task involves speech-to-text transcription, subtitle generation, translation, speaker-adjacent segmentation, or transcript cleanup using Whisper-compatible tooling.

## Workflow

- Inspect the media format, duration, language, noise level, and desired output format before processing.
- Extract or normalize audio when needed while preserving the source media.
- Choose timestamps, chunking, and language options that match the downstream use case.
- Verify transcripts against representative samples and flag uncertain names, jargon, or low-confidence spans.
