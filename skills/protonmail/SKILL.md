# ProtonMail

Discovery stub for a ProtonMail access skill.

Use when a user wants to search ProtonMail, triage unread mail, summarize important messages, or produce a private email digest through Proton Bridge-compatible access.

## Candidate Capabilities

- Connect through Proton Bridge or compatible IMAP bridge.
- Search mailboxes with date, sender, and keyword filters.
- Summarize important unread mail.
- Keep outbound sends behind explicit confirmation.
