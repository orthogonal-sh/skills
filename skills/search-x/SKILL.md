# Search X

Use this skill when the user needs current X/Twitter search results or social context.

## Workflow

1. Clarify keywords, accounts, time range, language, and exclusions.
2. Search for posts, replies, quotes, and account context.
3. Filter spam, duplicates, and low-quality engagement bait.
4. Summarize the strongest signals with links.
5. Separate observed claims from verified facts.

## Privacy

- Do not post, like, follow, or reply without explicit approval.
- Avoid exposing private conversation context in public searches.
