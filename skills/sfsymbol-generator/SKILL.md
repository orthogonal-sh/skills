# SF Symbol Generator

Use this skill when an Apple-platform project needs a custom SF Symbol asset catalog generated from an SVG.

## Notes

- Validate the SVG geometry before adding it to the asset catalog.
- Preserve naming conventions used by the Xcode project.
- Check the symbol in light, dark, and variable rendering contexts when relevant.
