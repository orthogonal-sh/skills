# Autoreview

Use this skill when a task involves automated code review, PR triage, diff analysis, regression risk checks, or review-comment preparation.

## Workflow

- Identify the target diff, base branch, changed files, tests, and review criteria.
- Prioritize bugs, regressions, security issues, missing tests, and contract breaks over style nits.
- Ground findings in file paths, line references, evidence, and reproducible reasoning.
- Summarize residual risk and verification gaps after the findings.
