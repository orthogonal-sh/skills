# Apple Docs MCP

Use this skill when Apple platform implementation depends on current official documentation.

## Workflow

- Identify the framework, symbol, platform, and OS version involved.
- Fetch or query official Apple docs before relying on memory.
- Compare APIs, availability, examples, and deprecation notes.
- Translate documentation into concrete implementation steps.
- Keep citations or source notes with any platform-specific recommendation.
