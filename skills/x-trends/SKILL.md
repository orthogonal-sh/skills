# X Trends

Use this skill when a task asks what is happening on X or how a topic is trending there.

## Workflow

- Clarify the topic, accounts, geography, language, and lookback window.
- Collect representative posts, engagement signals, account context, and external corroboration.
- Separate organic activity, coordinated campaigns, jokes, and breaking-news uncertainty.
- Summarize the narrative, notable accounts, evidence quality, and follow-up searches.
