# X Trends

Use this skill when the user needs current trending topics from X by country, region, or category.

## Workflow

- Select the target geography and freshness window.
- Fetch trend names, rank signals, and representative context from reliable sources.
- Group related trends and filter spam, slop, or ambiguous labels.
- Summarize why each trend appears to matter right now.
