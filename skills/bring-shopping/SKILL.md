# Bring Shopping

Use this skill when the user wants to read or update Bring shopping lists.

## When To Use

- List available Bring shopping lists.
- Add or remove grocery items.
- Check whether an item is already on a list.
- Prepare shopping lists from recipes or meal plans.

## Requirements

- Bring account credentials available to the local integration.
- The unofficial `bring-shopping` package or wrapper script installed.

## Workflow

1. List shopping lists.
2. Select the target list by exact name or ID.
3. Read current items before modifying.
4. Apply additions or removals.
5. Summarize the final list state.

## Safety

Ask before overwriting or clearing a list.
