# Pick UI Library

Use this skill when selecting a component library or design-system foundation.

## Workflow

- Gather framework, styling stack, accessibility requirements, and customization needs.
- Compare maintained options against the team's design goals and constraints.
- Consider bundle size, SSR support, docs, theming, form controls, and community health.
- Recommend one primary option plus credible alternatives.
- Include migration or adoption steps when the project already has UI code.
