# Context Compressor

Use this skill when a large amount of conversation, logs, or research needs to be condensed without losing what matters.

## Capabilities

- Summarize goals, constraints, decisions, file changes, and verification results.
- Preserve unresolved questions and risks separately from completed work.
- Produce compact handoffs suitable for follow-up sessions or background agents.
