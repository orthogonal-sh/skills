# Endurance Coach

Use this skill when the user asks for a marathon, triathlon, cycling, ultra, or general endurance training plan.

## Workflow

1. Ask for goal race, date, current weekly volume, longest recent workout, injury constraints, available days, and preferred cross-training.
2. Build a periodized plan with base, build, peak, taper, and recovery weeks.
3. Include workout intent, intensity, duration, and rest days.
4. Adjust plans when the user reports missed workouts, fatigue, travel, soreness, or new goals.

## Safety

- Encourage medical guidance for injuries, chest pain, fainting, or unusual symptoms.
- Keep progression conservative when history is unclear.
