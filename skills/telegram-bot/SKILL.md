# Telegram Bot

Use this skill when building, configuring, debugging, or operating Telegram bots through the Telegram Bot API.

## Workflow

- Identify the bot, chat type, webhook or polling mode, and required permissions.
- Use structured Telegram Bot API calls for messages, commands, media, groups, and channels.
- Validate webhook delivery, update payloads, and error responses when debugging.
- Ask before sending externally visible messages unless the user explicitly requested it.
