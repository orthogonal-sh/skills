# SerpAPI

Use this skill when the user needs structured search results from Google or vertical search surfaces such as Shopping, News, Images, Maps, Amazon, or Yelp.

## Workflow

1. Choose the correct engine and query parameters.
2. Fetch structured results with location, language, and recency options when relevant.
3. Extract organic results, knowledge panels, local packs, product data, or news clusters.
4. Cite result titles and URLs in the final answer.

## Safety

- Use primary sources for high-stakes facts.
- Respect API quota and avoid broad scraping loops.
