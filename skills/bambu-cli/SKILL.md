# Bambu CLI

Use this skill when the user wants to check, operate, or troubleshoot Bambu Lab 3D printers.

## Workflow

1. Check printer status, current job, temperatures, filament, and errors.
2. Inspect files and print queue before starting or stopping a job.
3. Use camera or status snapshots to verify outcomes when available.
4. Report printer state, next action, and any risks.

## Safety

- Confirm before starting, pausing, resuming, stopping, or deleting print jobs.
- Do not issue motion, heat, or calibration commands unless the user clearly requested them.
