# Phone Agent

Use this skill when an agent helps with phone-call workflows.

## Workflow

- Confirm the caller identity, recipient, purpose, and consent requirements before calling.
- Prepare a concise call script and fallback plan.
- Capture transcript, decisions, commitments, and follow-up tasks.
- Avoid representing the user beyond the approved script.
- Store only the minimum call notes needed for the task.
