# Home Assistant

Use this skill for smart-home state checks, automations, dashboards, and Home Assistant troubleshooting.

## Workflow

- Inspect available entities, areas, automations, and recent logs before changing state.
- Confirm before actions that affect locks, alarms, doors, appliances, or public-facing devices.
- Prefer reversible scene or automation updates.
- Record entity IDs and exact changes for repeatability.
- Verify final device state after commands.
