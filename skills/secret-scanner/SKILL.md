# Secret Scanner

Use this skill when checking code, logs, or configuration for leaked credentials.

## Capabilities

- Scan files, diffs, and history for API keys, tokens, and private material.
- Triage likely true positives versus test fixtures.
- Recommend rotation, revocation, and cleanup steps.
- Add ignore rules or regression checks for known safe examples.
