# Git Essentials

Use this skill when a task needs careful Git inspection or routine version-control work.

## Workflow

- Check branch, remotes, status, and recent commits before making changes.
- Preserve unrelated user work and avoid destructive commands unless explicitly requested.
- Use focused commits, clear messages, and branch names that match the task.
- Verify diffs, tests, and PR metadata before handing work back.
