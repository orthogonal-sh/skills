# Voice Call

Use this skill when a task involves phone calls, voice agents, call preparation, call summaries, voicemail handling, or transcript-based follow-up.

## Workflow

- Identify the callee, purpose, script or talking points, caller identity, and consent requirements.
- Require explicit confirmation before placing any outbound call.
- Capture outcomes, timestamps, voicemail status, transcript snippets, and follow-up tasks.
- Verify sensitive details such as phone numbers, appointment times, and commitments before acting.
