# PDF Form Filler

Use this skill when working with fillable PDFs or form-like documents.

## Workflow

- Inspect fields, field names, required values, constraints, and signature areas.
- Map source data to form fields before editing the document.
- Fill fields using a PDF-aware tool rather than visual text overlays when possible.
- Validate output by extracting field values or rendering pages.
- Preserve an original copy and document any flattening or signature implications.
