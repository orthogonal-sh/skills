# Job Auto Apply

Discovery stub for a job search and application workflow skill.

Use when a user wants to search job boards, evaluate role fit, tailor materials, or prepare applications. Actual submissions should require explicit user approval.

## Candidate Capabilities

- Search and filter jobs by constraints.
- Score fit against resume and preferences.
- Draft tailored resumes and cover notes.
- Track application status and next actions.
