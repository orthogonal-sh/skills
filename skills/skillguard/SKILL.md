# Skillguard

Use this skill when evaluating a skill before installation, sharing, or execution.

## Workflow

- Inspect metadata, trigger wording, referenced scripts, assets, and external links.
- Look for authority escalation, data exfiltration, destructive commands, and ambiguous permissions.
- Check that tool use is scoped to the stated purpose.
- Recommend edits that preserve usefulness while reducing risk.
- Summarize residual risk and whether the skill is safe to apply.
