# Weathercli

Use this skill when checking weather through a command-line weather source.

## Workflow

- Confirm the location, date range, units, and forecast detail needed.
- Fetch current conditions or forecast data from the CLI source.
- Highlight temperature, precipitation, wind, humidity, and alerts when present.
- Use absolute dates for relative requests when timing matters.
