# Node.js Backend Patterns

Use this skill when designing, implementing, or reviewing Node.js backend services.

## Workflow

1. Map service boundaries, runtime version, package manager, framework, and deployment target.
2. Keep configuration explicit, validate inputs at boundaries, and centralize error translation.
3. Review concurrency, timeouts, retries, cancellation, logging, metrics, and graceful shutdown.
4. Add tests at the smallest useful level, then cover critical integration paths.
