# NPM Search

Discovery stub for an npm package discovery skill.

Use when a user asks to find Node.js packages, compare libraries, inspect package metadata, or choose dependencies for a JavaScript or TypeScript project.

## Candidate Capabilities

- Search packages by keyword and intent.
- Compare downloads, maintenance, license, types, and repository health.
- Summarize package fit and risks.
- Produce install commands and usage pointers.
