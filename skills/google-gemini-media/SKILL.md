# google-gemini-media

Use this skill when Gemini is the right fit for multimodal analysis, media understanding, long-context media review, or Google-specific model workflows.

## Workflow

- Identify media type, file size, privacy constraints, desired model, and required output schema.
- Prepare inputs with clear prompts, timestamps, regions, or reference frames where useful.
- Ask for grounded observations before interpretation when visual or audio accuracy matters.
- Validate outputs against source media and flag uncertain detections, missing frames, or unsupported formats.
