# songsee

Use this skill when a task involves identifying a song, matching an audio clip, finding metadata, checking lyrics snippets, or resolving track/artist ambiguity.

## Workflow

- Gather the audio clip, link, lyrics fragment, timestamp, platform, and any contextual hints.
- Prefer direct audio fingerprinting or platform metadata before broad web search.
- Compare candidate tracks by title, artist, release, duration, and distinctive lyrics.
- Return confidence, alternatives, and source evidence when the match is uncertain.
