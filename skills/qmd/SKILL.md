# Qmd

Use this skill when searching local Markdown, notes, docs, or knowledge-base content with stronger retrieval than simple text search.

## Capabilities

- Index local documents for keyword, vector, and hybrid search.
- Retrieve relevant notes with citations and surrounding context.
- Support agent workflows that need local knowledge without cloud upload.
