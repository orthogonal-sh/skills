# QMD Knowledge Search

Use this skill when searching a local markdown notebook, docs tree, or project knowledge base.

## Workflow

1. Identify the root directory and topic.
2. Start with narrow keyword search, then expand to semantic search if needed.
3. Retrieve the most relevant files and line references.
4. Synthesize findings without copying large passages.
5. Save useful query patterns for repeated workflows.

## Tips

- Prefer source-backed answers.
- Distinguish current docs from stale notes.
- Do not index private folders outside the requested scope.
