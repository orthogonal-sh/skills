# internet-lookup-verifier

Use this skill when a task depends on current or disputed web facts, source attribution, quote verification, or a final confidence check before publishing an answer.

## Workflow

- Restate the claim, entity, date range, and what would count as verification.
- Search for primary sources first, then compare reputable secondary coverage when primary evidence is unavailable.
- Check publication dates, update timestamps, regional context, and whether sources quote each other.
- Report the verdict, evidence, caveats, and links or citations needed for follow-up.
