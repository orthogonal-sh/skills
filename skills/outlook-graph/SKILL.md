# Outlook Graph

Use this skill when the user wants to work with Outlook mail or calendar through Microsoft Graph.

## When To Use

- Search Outlook inboxes.
- Read, draft, or organize email.
- Inspect calendars and events.
- Manage folders, categories, or message state.

## Workflow

1. Confirm Microsoft Graph auth is configured.
2. Use read-only calls first.
3. Draft changes separately from sending.
4. Confirm before sending mail, deleting items, or modifying calendar events.

## Privacy

Email and calendar data are sensitive. Quote only the parts needed for the task.
