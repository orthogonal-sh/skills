# OpenAI TTS

Use this skill when the user wants spoken audio, narration, voice drafts, accessibility audio, or script-to-speech output.

## Workflow

1. Confirm script, tone, voice, pacing, format, and whether pronunciation hints are needed.
2. Prepare clean input text with stage directions removed or converted into prompt guidance.
3. Generate audio with the selected model and voice.
4. Check the output for truncation, pronunciation, noise, and timing before delivery.

## Notes

- Do not imitate a private person without clear authorization.
- Keep a copy of the exact script and generation settings for reproducibility.
