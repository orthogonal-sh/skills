# DDG Search

Use this skill when DuckDuckGo is an appropriate search source or fallback.

## Workflow

- Convert the user request into targeted web or news queries with useful operators.
- Compare results across multiple pages when the first page is thin or noisy.
- Prefer primary sources, official docs, and reputable reporting over SEO pages.
- Summarize results with links, dates, and caveats about freshness or ranking quality.
