# Quiver Quantitative

Use this skill when the user asks for alternative financial datasets exposed by Quiver Quantitative.

## When To Use

- Look up congressional trading activity.
- Inspect lobbying, government contracts, patents, or insider transaction datasets.
- Add alternative-data context to market research.

## Workflow

1. Identify the dataset and ticker or entity.
2. Fetch recent records.
3. Normalize dates, parties, amounts, and source links.
4. Summarize patterns without overstating causality.

## Disclaimer

This is research support, not financial advice. Data may lag or require interpretation.
