# Web Search

Use this skill when a task depends on current, niche, or externally sourced information.

## Workflow

- Clarify the target question, freshness requirements, and acceptable source types.
- Search broadly enough to avoid single-source bias, then narrow to primary or authoritative sources.
- Track source URLs, publication dates, and what each source supports.
- Call out uncertainty, conflicts, paywalls, or stale pages.
- Return the answer with concise source attribution and avoid over-quoting.
