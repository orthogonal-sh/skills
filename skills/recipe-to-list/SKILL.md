# Recipe To List

Use this skill when the user wants ingredients extracted from recipes and turned into an organized grocery list.

## Capabilities

- Extract ingredients from recipe URLs, pasted recipes, photos, or screenshots.
- Normalize quantities, units, duplicates, and pantry staples.
- Group shopping-list items by category or target task app.
