# Ponytail Gain

Use this skill when looking for practical improvements that create visible value without a large rewrite.

Scan for repeated pain, slow loops, unclear handoffs, missing automation, and easy quality wins, then rank ideas by expected payoff, effort, reversibility, and proof needed.
