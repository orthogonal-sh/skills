# Analytics Tracking

Use when the user asks to design, debug, or review analytics tracking for a website, product, funnel, or campaign.

## Workflow

- Identify business questions before proposing events.
- Define event names, properties, identity rules, and privacy constraints.
- Map instrumentation points to user actions and backend state changes.
- Include QA checks for duplicates, missing events, and attribution gaps.
