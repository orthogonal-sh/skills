# Writing Issues

Use this skill when creating or revising work items for bugs, features, chores, spikes, migrations, or follow-up tasks.

Make the issue independently actionable: include the problem, observed evidence, desired behavior, scope boundaries, acceptance criteria, dependencies, and the smallest useful verification path.
