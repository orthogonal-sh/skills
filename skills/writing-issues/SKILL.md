# Writing Issues

Use this skill when creating or refining tickets for bugs, features, chores, or research.

## Workflow

1. Capture the problem, user impact, priority, and relevant context.
2. Add reproduction steps, screenshots, logs, or links for bugs.
3. Define acceptance criteria and out-of-scope boundaries.
4. Include implementation notes, dependencies, and test expectations.
5. Assign labels, owners, project, milestone, and related work when available.

## Checks

- Make the title specific enough to scan in a backlog.
- Avoid bundling unrelated work into one issue.
- Distinguish desired outcome from suggested implementation.
- Include verification steps so done means done.
