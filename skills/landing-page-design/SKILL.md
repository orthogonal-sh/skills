# Landing Page Design

Use this skill when creating or reviewing a marketing landing page.

## Workflow

- Clarify the audience, offer, brand, conversion goal, and proof points.
- Make the first viewport communicate what the product is and why it matters.
- Structure sections around objections, differentiation, examples, and calls to action.
- Check copy, imagery, hierarchy, trust signals, mobile layout, and load performance.
- Avoid generic decorative layouts when product-specific visuals would communicate better.
