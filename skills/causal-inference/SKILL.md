# Causal Inference

Use when a user wants to understand whether an action caused an observed outcome, compare interventions, or reason about evidence quality.

## Suggested Workflow

- Define the outcome, treatment, population, and timeframe.
- List plausible confounders and alternative explanations.
- Prefer experiments, natural experiments, or quasi-experimental designs when available.
- State what evidence would change the conclusion.
