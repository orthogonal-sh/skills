# Standard Agentic Commerce Engine

Use this skill when an agent needs standardized product discovery, cart operations, checkout preparation, or user-management workflows against a compatible commerce backend.

## Notes

- Ask before purchases, account changes, or payment actions.
- Separate browsing/cart preparation from checkout authorization.
- Log product identifiers, quantities, and prices for auditability.
