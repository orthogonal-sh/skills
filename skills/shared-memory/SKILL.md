# Shared Memory

Use this skill when the user wants durable knowledge shared between multiple people, agents, or workspaces.

## When To Use

- Set up team knowledge that several agents can read.
- Grant or revoke access to a project memory space.
- Publish selected notes without exposing private memory.
- Subscribe to memory changes from another workspace.

## Permission Model

Before sharing anything, define:

- Owner
- Recipients
- Scope
- Read or write access
- Expiration or review date

## Safe Workflow

1. Identify the exact memory items to share.
2. Remove secrets, personal details, and unrelated context.
3. Ask for approval before creating or broadening access.
4. Record what was shared, with whom, and why.

## Default

Share the smallest useful slice. Private memory stays private unless the user explicitly says otherwise.
