# Timesheet

Use this skill when the user needs to track time, summarize work, or report hours by project or task.

## Capabilities

- Start, stop, edit, and annotate time entries.
- Group time by project, task, date, client, or tag.
- Generate daily, weekly, and project-level time reports.
