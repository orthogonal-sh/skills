# Himalaya

Use this skill when a user wants terminal-based email listing, reading, searching, composing, replying, forwarding, or mailbox organization through Himalaya.

## Notes

- Verify account configuration before sending or moving mail.
- Ask before sending messages or taking externally visible email actions.
- Prefer read-only searches and drafts during triage.
