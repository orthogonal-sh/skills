# Google Search Console

Use when a user asks about organic search performance, search queries, indexing status, sitemap coverage, or SEO opportunities for a verified property.

## Suggested Actions

- Identify the property and date range.
- Pull query, page, country, device, and CTR metrics as needed.
- Compare periods when diagnosing drops or wins.
- Distinguish Search Console data from analytics or rank-tracking data.

## Candidate Sources

- OpenClaw `gsc`
- Google Search Console API
