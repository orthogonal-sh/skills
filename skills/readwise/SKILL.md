# Readwise

Use this skill when a user wants to search, summarize, export, or connect highlights and saved reading from Readwise or Reader.

## Notes

- Preserve source titles, authors, and URLs in summaries.
- Distinguish direct highlights from assistant-written synthesis.
- Avoid exposing private reading history in shared contexts.
