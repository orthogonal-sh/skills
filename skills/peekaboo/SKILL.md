# Peekaboo

Use when the user needs local screen inspection, visual progress checks, app-window awareness, or screenshot-based automation support.

## Workflow

- Capture only the needed screen or window region.
- Avoid exposing private screen content outside the local task.
- Use screenshots to verify progress before interacting.
- Summarize visual findings without overclaiming hidden state.
