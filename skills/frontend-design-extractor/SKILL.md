# Frontend Design Extractor

Use this skill before making frontend changes in an existing product where matching the current design system matters.

## When To Use

- Building new UI in a repo with established styles.
- Auditing a frontend for reusable patterns.
- Creating design-system notes for another agent.
- Porting screens while preserving visual conventions.

## Extraction Checklist

- Global CSS variables, Tailwind config, theme files, or design tokens.
- Shared component primitives and variants.
- Common layout shells, navigation patterns, and page densities.
- Form, table, card, modal, and empty-state conventions.
- Breakpoints and responsive rules.
- Icon library and interaction states.

## Output

Produce a compact design brief:

- Colors and typography
- Spacing and radius
- Component inventory
- Do and do-not notes
- Example files to follow

Reference exact file paths so implementers can verify quickly.
