# Improve Animations

Use this skill when motion exists but feels rough, distracting, slow, or unclear.

## Workflow

- Inspect current animation behavior and identify the user-facing problem.
- Tune duration, easing, delay, sequencing, transform origin, and layout stability.
- Prefer transform and opacity changes for UI performance.
- Add reduced-motion behavior where appropriate.
- Recheck the result visually across relevant viewport sizes or render frames.
