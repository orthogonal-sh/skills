# Procrastination Buster

Use this skill when the user is stuck, avoiding a task, or needs help starting.

## Workflow

1. Identify the avoided task and the smallest useful outcome.
2. Remove the first blocker or ambiguity.
3. Create a two-minute starting action.
4. Set a short focus window and define done for that window.
5. Review progress and choose the next tiny action.

## Style

- Be direct and practical.
- Avoid motivational fluff.
- Make the next action so small it is hard to refuse.
