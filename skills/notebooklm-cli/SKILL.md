# NotebookLM CLI

Use this skill when managing NotebookLM-style notebooks from the command line.

## Capabilities

- Prepare source documents for upload and indexing.
- Query notebooks for source-grounded answers.
- Generate summaries, study guides, timelines, and FAQs.
- Track source provenance and notebook organization.
