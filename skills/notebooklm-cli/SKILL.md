# NotebookLM CLI

Use this skill when managing NotebookLM-style notebooks or source-grounded summaries from the command line.

## Workflow

- Identify the notebook, source documents, and desired answer or summary type.
- Add, list, refresh, or query sources through the available CLI workflow.
- Keep answers grounded in notebook sources and cite source names when possible.
- Summarize missing coverage when the notebook does not contain enough evidence.
