# Voicenotes

Use this skill when the user wants to work with content stored in Voicenotes.

## When To Use

- List recent voice notes.
- Fetch transcripts or summaries.
- Search voice notes for a topic.
- Convert spoken notes into tasks, drafts, or meeting notes.

## Workflow

1. Authenticate with the Voicenotes integration.
2. Fetch recent or matching notes.
3. Preserve timestamps and titles.
4. Summarize or transform only the selected notes.

## Privacy

Voice notes may contain sensitive personal content. Quote sparingly and only when needed.
