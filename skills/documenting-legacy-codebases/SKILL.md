# Documenting Legacy Codebases

Use this skill when documenting an unfamiliar or older system so future changes can happen with less guesswork.

Start from observed code and runtime evidence, map the major modules and data paths, note fragile assumptions, and distinguish verified behavior from hypotheses that still need checking.
