# PRD

Use when a user asks to define a product feature, turn an idea into requirements, or align implementation around expected behavior.

## Suggested Structure

- Problem and target users.
- Goals, non-goals, and success metrics.
- User stories and acceptance criteria.
- Dependencies, risks, launch plan, and open questions.

- OpenClaw `prd`
