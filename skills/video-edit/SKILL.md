# Video Edit

Use this skill when a user asks to edit video, prepare social clips, cut footage, add captions, change aspect ratio, compress media, or export alternate versions.

## Workflow

- Confirm the target platform, aspect ratio, duration, and output format when they matter.
- Preserve the original media and write edited outputs to a clearly named new file.
- Use proven media tools such as ffmpeg, Remotion, or the project-standard video stack.
- Verify duration, dimensions, codec, and file size after export.
- Provide a short summary of edits and output paths.
