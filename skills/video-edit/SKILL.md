# Video Edit

Use this skill when planning or executing practical video edits.

## Workflow

- Identify the source media, target platform, duration, aspect ratio, and delivery format.
- Build a cut list with pacing, transitions, captions, audio, and overlays.
- Prefer reproducible edit commands or project instructions when possible.
- Check safe areas, loudness, subtitle readability, and export settings.
- Verify the output or representative frames before final delivery.
