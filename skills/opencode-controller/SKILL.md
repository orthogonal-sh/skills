# OpenCode Controller

Use this skill when a task involves launching, steering, or auditing OpenCode work.

## Workflow

- Clarify the repo, objective, branch constraints, tools allowed, and expected verification.
- Provide OpenCode with scoped context, concrete success criteria, and files to inspect first.
- Monitor outputs, diffs, tests, and unresolved questions before accepting results.
- Summarize changes and residual risk in a way another agent or engineer can continue.
