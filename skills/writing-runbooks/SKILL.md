# Writing Runbooks

Use this skill when creating or improving operational runbooks.

## Workflow

1. Define the service, alert, failure mode, severity, and owner.
2. Document symptoms, dashboards, logs, commands, and expected outputs.
3. Provide step-by-step triage, mitigation, rollback, and escalation paths.
4. Include verification steps for recovery and customer impact.
5. Add links to related incidents, architecture docs, and playbooks.

## Checks

- Keep commands copy-safe and environment-specific values explicit.
- Mark destructive or customer-impacting steps clearly.
- Include when to stop and escalate.
- Test the runbook against a realistic scenario when possible.
