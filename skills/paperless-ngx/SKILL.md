# Paperless-ngx

Use this skill when a task involves Paperless-ngx document search, OCR text, tags, correspondents, document types, ingestion, or archives.

## Workflow

- Identify the Paperless-ngx instance, document IDs, search terms, tags, correspondents, and desired action.
- Search before changing metadata, and inspect OCR text, dates, archive paths, and existing classification conventions.
- Keep document edits scoped; avoid deleting or reprocessing originals without explicit intent.
- Verify changed metadata, saved views, ingestion status, and searchability.
