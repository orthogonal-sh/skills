# Context Optimizer

Use this skill when deciding what context to keep, drop, summarize, or reload during long-running work.

## Stub Scope

- Preserve user intent, constraints, current state, and irreversible decisions.
- Drop duplicated logs, obsolete exploration, and low-value transcripts.
- Make summaries query-aware so future work can restart cleanly.
