# Recruitment Automation

Use this skill when the user asks for a recruiting pipeline or candidate evaluation workflow.

## When To Use

- Turn a job spec into search criteria.
- Source candidates from public profiles or approved databases.
- Score candidates against required and nice-to-have criteria.
- Draft recruiter notes, outreach, or interview plans.

## Workflow

1. Extract role requirements and disqualifiers.
2. Define a scoring rubric.
3. Collect candidate evidence with source links.
4. Score each candidate conservatively.
5. Produce a shortlist and open questions.

## Safety

- Do not infer protected-class attributes.
- Keep evidence source-based.
- Get approval before contacting candidates.
