# Satori

Use this skill when work needs durable memory across sessions, tools, or coding-agent providers.

## Capabilities

- Capture stable project knowledge, preferences, and recurring decisions.
- Retrieve relevant prior context before acting on related work.
- Sync or translate memory practices between different agent environments.
