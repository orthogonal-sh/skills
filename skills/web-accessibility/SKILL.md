# Web Accessibility

Use this skill when building, reviewing, or fixing accessibility in web interfaces.

## Workflow

1. Check semantic structure, labels, landmarks, heading order, and accessible names.
2. Verify keyboard navigation, focus visibility, dialogs, menus, forms, and error announcements.
3. Confirm color contrast and responsive behavior without relying only on automated tools.
4. Add tests for critical interactions and run available accessibility checks.
