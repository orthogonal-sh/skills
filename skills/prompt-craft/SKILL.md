# Prompt Craft

Use this skill when a prompt is a reusable interface rather than a one-off message.

## Workflow

- Define the model role, task boundary, inputs, outputs, and success criteria.
- Make constraints explicit and remove ambiguous or conflicting instructions.
- Include examples only when they clarify behavior.
- Test against likely edge cases, missing inputs, and adversarial content.
- Revise for brevity, observability, and predictable failure handling.
