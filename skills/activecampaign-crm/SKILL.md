# ActiveCampaign CRM

Use this skill when a task involves ActiveCampaign CRM or marketing automation.

## When To Use

- Search, create, or update contacts.
- Manage tags, lists, deals, or pipeline stages.
- Review automation membership.
- Prepare campaign drafts or segmentation rules.

## Workflow

1. Identify the target contact, account, list, or deal.
2. Fetch current fields before updating.
3. Apply the minimal change.
4. Record source and reason in a note when appropriate.

## Safety

Confirm before sending email, enrolling contacts in automations, or making bulk updates.
