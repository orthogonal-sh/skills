# Writing Changelogs

Use this skill when preparing release notes, changelog entries, migration summaries, or customer-facing update notes.

Group changes by user impact, include breaking changes and upgrade steps plainly, avoid commit-log noise, and mention deprecations, security fixes, and operational actions where relevant.
