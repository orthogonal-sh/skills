# Coding Agent User Rules

Use when the user wants durable instructions for coding agents, repository workflows, or personal engineering preferences.

## Workflow

- Distinguish one-time preferences from standing rules.
- Keep rules concrete, testable, and scoped to the right repo or environment.
- Preserve user-specific safety boundaries around git, secrets, and external actions.
- Suggest installation or documentation locations only after inspecting the project.
