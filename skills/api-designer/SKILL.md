# API Designer

Use this skill when planning, reviewing, or documenting an API.

## When To Use

- Define REST resources or GraphQL schemas.
- Create or review OpenAPI specifications.
- Choose pagination, filtering, idempotency, auth, and versioning patterns.
- Improve error responses and developer experience.

## Design Checklist

- Primary users and workflows
- Resource boundaries and naming
- Authentication and authorization
- Pagination and rate limits
- Error model
- Idempotency for writes
- Webhooks and async jobs
- Examples for common calls

## Output Pattern

Return:

- Proposed endpoints or schema
- Request and response examples
- Error cases
- Tradeoffs
- Open questions

Keep examples minimal but complete enough to implement.
