# API Designer

Use this skill when designing REST APIs, GraphQL schemas, OpenAPI specs, resource models, versioning, or developer-facing API docs.

## Stub Scope

- Model resources around user intent and stable domain concepts.
- Specify authentication, pagination, filtering, idempotency, rate limits, and error shapes.
- Produce concrete endpoint or schema drafts instead of vague architecture advice.
