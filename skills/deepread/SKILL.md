# Deepread

Use when the user provides a long document, paper, report, transcript, or book excerpt and wants more than a shallow summary.

## Workflow

- Identify the document type, author intent, audience, and core claims.
- Build a structured outline before summarizing.
- Track evidence, assumptions, contradictions, and missing context.
- Return concise takeaways with citations or section references when possible.
