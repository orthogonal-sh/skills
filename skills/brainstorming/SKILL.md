# Brainstorming

Use this skill when the user wants structured ideation before committing to a direction.

## Requirements

- Goal, constraints, and audience

## Suggested Actions

- Generate diverse options
- Cluster ideas by theme
- Evaluate tradeoffs
- Recommend a short list of next steps
