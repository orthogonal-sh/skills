# Clean Code

Use this skill when reviewing or editing code for clarity, maintainability, duplication, naming, or over-engineering.

## Stub Scope

- Prefer direct, readable code over clever abstractions.
- Keep functions focused and remove meaningful duplication.
- Add comments only where they explain non-obvious intent or constraints.
