# Clean Code

Use this skill when reviewing or refactoring code for clarity and maintainability.

## Workflow

1. Read the surrounding code before proposing changes.
2. Remove meaningful duplication and simplify control flow.
3. Improve names, boundaries, and tests where the change reduces confusion.
4. Keep unrelated refactors out of the diff.

## Notes

- Prefer boring, local improvements.
- Comments should explain why, not restate what the code says.
