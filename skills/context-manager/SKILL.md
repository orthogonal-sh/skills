# Context Manager

Use this skill when a session is long, information is scattered, or future agents will need a clear continuity trail.

## Capabilities

- Extract durable facts, open decisions, and next actions from active work.
- Prepare concise handoffs before compaction or agent transfer.
- Keep context small by distinguishing current task state from archival detail.
