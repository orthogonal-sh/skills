# Context Manager

Use this skill when a session is becoming long, slow, hard to follow, or close to context limits.

## Stub Scope

- Preserve active goals, decisions, files touched, blockers, and pending verification.
- Separate durable memory from transient working notes.
- Avoid destructive session reset or compaction without explicit user or runtime permission.
