# Prompt Defense

Use this skill when reviewing or hardening prompts, tools, retrieval pipelines, or agent behavior against prompt injection.

## Capabilities

- Identify untrusted instructions in web pages, documents, and tool outputs.
- Separate system policy from retrieved or user-controlled content.
- Propose guardrails for tool calls, data exfiltration, and external actions.
- Test prompts against adversarial examples.
