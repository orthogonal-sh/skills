# Alexa CLI

Discovery stub for an Alexa device control skill.

Use when a user wants to announce messages, control smart-home devices, inspect available Alexa devices, or send voice-style commands through a CLI.

## Candidate Capabilities

- List configured Alexa devices.
- Send announcements or commands.
- Control compatible smart-home devices.
- Require confirmation before disruptive actions.
