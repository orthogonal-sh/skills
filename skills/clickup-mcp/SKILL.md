# ClickUp MCP

Use when a user asks to search, create, update, or organize ClickUp tasks, docs, lists, spaces, comments, or time entries.

## Suggested Workflow

- Identify the ClickUp workspace, space, list, or task before making changes.
- Read existing task state before updating fields or comments.
- Ask before sending externally visible comments or changing assignments.
- Preserve task IDs and links in summaries.

## Candidate Sources

- OpenClaw `clickup-mcp`
- ClickUp MCP server and ClickUp API
