# ClickUp MCP

Use this skill when working with ClickUp workspaces through the official ClickUp MCP server.

## Workflow

1. Verify authentication and workspace access.
2. Search before creating duplicate tasks or docs.
3. Use structured task fields for status, assignee, priority, due date, tags, and parent.
4. Summarize changes with ClickUp task IDs or URLs.

## Safety

- Ask before changing task status in ambiguous cases.
- Keep comments concise and attributable.
