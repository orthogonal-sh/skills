# Prisma Database Setup

Use this skill when a project needs Prisma added, configured, migrated, or connected to a local or hosted database.

## Workflow

- Inspect existing database, ORM, migration, and environment patterns first.
- Add or update Prisma schema using the project naming and folder conventions.
- Use placeholders for secrets and never invent real credentials.
- Run format, validate, generate, and migration commands appropriate to the project.
- Add focused tests or seed checks when model behavior changes.
