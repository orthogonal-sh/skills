# WhatsApp Styler

Use this skill before drafting WhatsApp messages so formatting matches platform expectations and stays readable on small screens.

## Notes

- Avoid markdown tables and complex nested formatting.
- Keep links, bullets, and emphasis compact.
- Preserve the user's tone while making the message easy to scan.
