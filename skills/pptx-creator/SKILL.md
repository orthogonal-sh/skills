# PPTX Creator

Use this skill when the user wants a presentation deck, slide outline, PowerPoint edits, or export-ready narrative.

## Workflow

1. Clarify audience, goal, length, format, brand constraints, and required assets.
2. Build an outline with one purpose per slide.
3. Create or edit slides with consistent layout, typography, charts, and speaker notes.
4. Review for flow, factual accuracy, visual clutter, and export issues.

## Notes

- Prefer user-provided brand assets when available.
- Keep slide text concise and move detail to notes.
