# PowerPoint Creator

Use this skill when the user wants a presentation, slide outline, PowerPoint file, speaker notes, or a visual deck from source material.

## Workflow

1. Clarify audience, objective, slide count, tone, template, and required assets.
2. Build a slide plan before creating the file.
3. Turn source material into concise slide copy, speaker notes, charts, and image prompts.
4. Generate or update the PPTX and verify basic layout integrity.

## Safety

- Do not invent data. Label assumptions and placeholders.
- Keep private source material out of reusable templates.
