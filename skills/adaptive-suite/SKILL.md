# Adaptive Suite

Use this skill when a request spans several disciplines and needs the agent to choose an appropriate working mode before acting.

## Capabilities

- Classify the task as coding, analysis, project management, web work, data work, or operations.
- Select a practical workflow and verification style for the task type.
- Keep cross-domain work organized without forcing a single rigid process.
