# Transcribee

Use this skill when the user wants a transcript from audio, video, a podcast, a meeting recording, or YouTube.

## Workflow

1. Identify the media source, language, desired format, and whether speaker diarization is needed.
2. Extract or download audio when necessary.
3. Run transcription with timestamps and speaker labels when available.
4. Produce the requested export: plain text, Markdown, SRT, VTT, summary, or action items.

## Safety

- Treat recordings as private.
- Avoid publishing transcripts or files externally without approval.
