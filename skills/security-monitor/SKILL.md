# Security Monitor

Use this skill when checking whether systems show signs of security risk or active incidents.

## Workflow

- Define the assets, alerts, logs, scanners, and time window to inspect.
- Prioritize public exposure, credentials, suspicious access, and known exploited vulnerabilities.
- Correlate signals before escalating noisy findings.
- Record severity, evidence, affected systems, and recommended containment.
- Close the loop with verification after remediation.
