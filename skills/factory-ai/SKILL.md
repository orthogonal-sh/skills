# Factory AI

Use this skill when working with Factory AI-style coding agents or automation runners.

## Capabilities

- Prepare scoped coding tasks for autonomous execution.
- Monitor agent output, diffs, and verification results.
- Convert failed runs into smaller follow-up tasks.
- Summarize completed agent work for review.
