# Brave Search

Use this skill when a task involves Brave Search, web result discovery, news/search freshness, or source-backed research workflows.

## Workflow

- Clarify the search intent, freshness requirements, geography, and source-quality bar.
- Use targeted queries and compare multiple independent sources for important claims.
- Track result URLs, dates, snippets, and uncertainty.
- Summarize findings with source attribution and note when search results are thin or conflicting.
