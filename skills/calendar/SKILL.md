# Calendar

Use this skill when the user asks about schedule, meetings, availability, reminders tied to events, or calendar changes.

## Workflow

- Confirm the calendar account, timezone, date range, and whether changes should be made.
- Search existing events before creating duplicates.
- Preserve attendees, conferencing links, notes, recurrence, and location metadata during updates.
- Highlight conflicts, travel buffers, and uncertain event details.
- Ask before sending invitations or changing attendee-visible fields.
