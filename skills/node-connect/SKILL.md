# Node Connect

Use this skill when a task involves OpenClaw node setup, pairing, QR codes, route failures, authentication problems, mobile nodes, desktop nodes, or connectivity diagnostics.

## Workflow

- Identify the node platform, pairing method, gateway, route, account, and observed failure.
- Inspect connection state, logs, auth tokens, network reachability, and version compatibility.
- Prefer reversible diagnostics and config preservation before making changes.
- Verify the node appears online and can perform a simple round-trip action.
