# App Store Screenshots

Use this skill when preparing iOS, iPadOS, Android, or cross-platform app store screenshots and promotional image sets.

Match current store size requirements, show real product value in the first frames, keep captions short and legible, verify device crops, and track variants for localization and experiments.
