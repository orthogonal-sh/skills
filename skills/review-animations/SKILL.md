# Review Animations

Use this skill when evaluating motion in an interface, prototype, or video.

## Workflow

- Inspect the animation's purpose, timing, easing, staging, and continuity.
- Check whether motion clarifies state changes or distracts from the task.
- Look for layout shift, jank, inaccessible flashing, and reduced-motion handling.
- Suggest concrete adjustments with durations, easing, sequencing, or removal.
- Verify improvements with a preview when possible.
