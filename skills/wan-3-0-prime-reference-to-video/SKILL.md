# Wan 3.0 Prime Reference To Video

Use this skill when turning a reference image or visual brief into a video-generation prompt.

## Workflow

- Describe the source image, subject identity, camera framing, and visual style.
- Specify motion, shot duration, lens behavior, environment changes, and constraints.
- Preserve important details while avoiding impossible or conflicting instructions.
- Generate prompt variants for different motion intensities or aspect ratios.
- Review outputs for identity drift, artifacts, temporal consistency, and framing.
