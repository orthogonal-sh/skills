# Expo API Routes

Use this skill when implementing or debugging API routes in Expo projects.

## Workflow

1. Confirm the Expo Router version, runtime target, route files, and deployment platform.
2. Validate request parsing, auth boundaries, response shapes, and error handling.
3. Keep server-only code isolated from client bundles.
4. Test handlers with representative requests and platform-specific constraints.
