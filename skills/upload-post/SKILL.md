# Upload Post

Use this skill when publishing or scheduling content through Upload-Post.

## Workflow

1. Confirm the target platform, account, content, caption, media, and timing.
2. Validate media format, dimensions, and platform limits.
3. Draft the final post for approval before publishing.
4. Report the platform response and public URL when available.

## Safety

- Posting is an external action. Ask before publishing.
- Do not post private work details or conversation context.
