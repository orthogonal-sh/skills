# Relay To Agent

Use this skill when handing work from one agent or session to another.

## Workflow

- State the objective, current state, constraints, and success criteria.
- Include only the files, facts, and history needed for the receiving agent.
- Preserve privacy boundaries and omit unrelated personal context.
- Ask for a concrete output format and verification notes.
- Reconcile the returned result before presenting it as finished work.
