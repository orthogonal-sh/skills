# Resume Optimizer

Discovery stub for a resume creation and optimization skill.

Use when a user needs to create a resume, tailor an existing resume to a job description, analyze ATS fit, or produce a polished export.

## Candidate Capabilities

- Compare resume content against job descriptions.
- Suggest stronger bullets and missing keywords.
- Generate role-specific versions.
- Export structured markdown or PDF-ready content.
