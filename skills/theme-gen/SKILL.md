# Theme Gen

Use when the user asks for a visual theme, color system, design tokens, or dark/light palette variants.

## Workflow

- Clarify brand constraints, medium, accessibility target, and component needs.
- Produce semantic tokens rather than only raw colors.
- Check contrast for text, surfaces, borders, focus, and status colors.
- Include implementation-friendly formats such as CSS variables or JSON.
