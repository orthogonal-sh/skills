# Screen Monitor

Use this skill when a visual workflow needs periodic inspection or state recognition.

## Workflow

- Define the expected screen, target region, and stop conditions.
- Capture screenshots at a cadence that matches the workflow.
- Compare visible state against known progress, error, and completion cues.
- Avoid interacting unless the task explicitly calls for it.
- Report concise observations with timestamps and next recommended action.
