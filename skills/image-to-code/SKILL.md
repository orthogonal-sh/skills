# Image To Code

Use this skill when the user provides a screenshot, mockup, or visual reference and wants code that recreates it.

## Workflow

- Inspect the reference for layout, typography, spacing, colors, controls, and responsive constraints.
- Identify the target framework and existing design system before writing code.
- Build the smallest complete implementation that matches the visible interface.
- Preserve accessibility, loading states, and mobile behavior.
- Verify the rendered result with screenshots when a dev server is available.
