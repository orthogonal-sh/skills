# Image To Code

Use this skill when a user provides a screenshot, mockup, or design image and wants an implementation.

## Workflow

- Inspect layout, spacing, typography, colors, assets, and responsive implications.
- Reuse existing components and design tokens before adding new ones.
- Implement the closest practical version in the project's framework.
- Verify against the reference with screenshots.
- Add tests for meaningful interactions and user flows.
