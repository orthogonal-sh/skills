# OpenClaw Feeds

Use this skill when watching feeds for news, releases, posts, or project updates.

## Workflow

- Identify feed URLs, topics, cadence, notification thresholds, and quiet hours.
- Fetch entries with timestamps, GUIDs, links, and deduplication keys.
- Summarize new items by relevance and avoid reposting unchanged feed entries.
- Store last-seen state where appropriate and report errors or broken feeds.
