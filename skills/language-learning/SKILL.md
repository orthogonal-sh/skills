# Language Learning

Use this skill when the user wants to learn or practice a language through tutoring, drills, roleplay, or review.

## Capabilities

- Run vocabulary, grammar, pronunciation, reading, and conversation exercises.
- Adapt difficulty to the learner's level and goals.
- Create study plans, quizzes, corrections, and spaced-review prompts.
