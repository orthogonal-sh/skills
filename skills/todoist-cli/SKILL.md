# Todoist CLI

Use this skill when the user asks to list, add, edit, complete, postpone, or organize Todoist tasks.

## Workflow

1. Clarify the project, label, priority, due date, and task text.
2. Search existing tasks before creating duplicates.
3. Add or update tasks with concise names and useful descriptions.
4. Confirm destructive changes such as deleting many tasks.
5. Summarize changed tasks with IDs or links.

## Task Hygiene

- Use concrete verbs.
- Keep due dates realistic.
- Separate tasks from notes when possible.
