# Security Skill Scanner

Use this skill when auditing a skill repository or marketplace package.

## Workflow

- Inventory skill files, scripts, dependencies, and referenced network endpoints.
- Check for credential reads, shell execution, persistence, downloads, and data exfiltration.
- Compare declared capabilities with actual behavior.
- Flag risky patterns with evidence and severity.
- Recommend quarantine, edits, or approval with explicit rationale.
