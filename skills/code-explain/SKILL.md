# Code Explain

Use this skill when the user wants to understand code rather than immediately change it.

## Workflow

- Read the relevant files and tests before explaining behavior.
- Trace inputs, outputs, side effects, and important dependencies.
- Use concrete file and symbol references.
- Distinguish what the code does today from what it appears intended to do.
- Keep explanations proportional to the user's question.
