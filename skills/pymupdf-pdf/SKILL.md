# pymupdf-pdf

Use this skill when a PDF task needs reliable local parsing, rendering, extraction, redaction, splitting, merging, or page-level inspection with PyMuPDF.

## Workflow

- Inspect the PDF structure, page count, text layer, images, forms, annotations, and encryption state.
- Choose text extraction, block extraction, image extraction, rendering, or OCR based on document quality.
- Preserve page numbers, coordinates, metadata, and uncertainty for scanned or complex layouts.
- Verify edits or exports by re-opening the output and checking page count, visible content, and redaction safety.
