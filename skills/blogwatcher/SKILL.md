# Blogwatcher

Use this skill when a task involves watching blogs, RSS/Atom feeds, changelogs, documentation sites, or publication streams for new or changed content.

## Workflow

- Identify target sources, polling cadence, inclusion/exclusion rules, and alert thresholds.
- Prefer feeds, sitemaps, APIs, or structured metadata before scraping pages directly.
- Deduplicate by canonical URL, GUID, title, and publication timestamp.
- Summarize notable changes with source links, dates, and why they matter.
