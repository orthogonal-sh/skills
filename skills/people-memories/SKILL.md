# People Memories

Use this skill when the user asks to remember details about a person or when prior relationship context would improve a task.

## Capabilities

- Store concise, respectful notes about people and preferences.
- Recall relevant details for messages, meetings, gifts, follow-ups, and planning.
- Avoid oversharing private context in group or external settings.
