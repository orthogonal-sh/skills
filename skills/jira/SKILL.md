# Jira

Use this skill when a task involves Jira tickets, projects, boards, sprints, epics, workflows, releases, or issue reporting.

## Workflow

- Identify the Jira site, project, board, issue keys, and whether the action is read-only or mutating.
- Use precise JQL or issue keys, then inspect linked issues, status, assignee, priority, labels, comments, and sprint context.
- Keep ticket edits scoped and auditable; avoid changing workflow state without clear intent.
- Report the resulting issue list, changes made, open blockers, and suggested next actions.
