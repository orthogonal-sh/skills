# Webhook Gen

Use this skill when adding or consuming webhook events.

## Workflow

- Define event types, payload schema, delivery semantics, and retry behavior.
- Add signature verification, timestamp checks, and replay protection.
- Make handlers idempotent and observable.
- Provide local test fixtures and sample curl or replay commands.
- Document failure modes, rate limits, and operational runbooks.
