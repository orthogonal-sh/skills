# Save Money

Use when a user wants lower AI costs, cheaper routing, or model selection based on task complexity.

## Suggested Workflow

- Classify task complexity, risk, context size, and tool needs.
- Use inexpensive models for simple extraction, summarization, drafting, and classification.
- Escalate for high-stakes reasoning, code changes, or ambiguous tasks.
- Track assumptions and avoid quality regressions that cost more later.

## Candidate Sources

- OpenClaw `save-money`
- Model routing, budget controls, and usage logs
