# Transitions Dev

Use this skill when adding, reviewing, or debugging page transitions, route animations, shared element motion, interaction feedback, or stateful UI transitions.

Preserve orientation and continuity, respect reduced-motion settings, avoid layout jank, and verify the transition at realistic desktop and mobile sizes before calling it finished.
