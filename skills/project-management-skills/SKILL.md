# Project Management Skills

Use this skill when planning, coordinating, or tracking complex projects that need explicit scope, ownership, dependencies, risks, and follow-through.

## Capabilities

- Turn vague requests into project plans with goals, milestones, tasks, and acceptance criteria.
- Identify conflicts, blockers, dependencies, and decision points before work starts.
- Maintain project context across sessions with concise status updates and handoffs.
