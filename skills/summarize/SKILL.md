# Summarize

Use this skill when the main value is extracting signal from a larger source.

## Workflow

- Identify the audience, desired length, and whether actions, decisions, or quotes matter.
- Preserve dates, names, numbers, and commitments accurately.
- Separate summary, open questions, and next actions when useful.
- Avoid overquoting copyrighted sources.
- State uncertainty when source material is incomplete or contradictory.
