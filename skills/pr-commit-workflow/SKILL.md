# PR Commit Workflow

Use this skill when turning local work into a reviewable pull request.

## Workflow

- Inspect the worktree and separate task changes from unrelated edits.
- Run focused formatting, linting, tests, or validation before committing.
- Write a commit message that matches the project style.
- Create a PR body with summary, verification, risk, and follow-up notes.
- Confirm the pushed branch and PR URL before reporting completion.
