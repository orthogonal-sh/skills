# Apple Docs

Use this skill when a task involves Swift, SwiftUI, UIKit, AppKit, platform APIs, or WWDC guidance.

## When To Use

- Verify Apple API behavior.
- Find framework documentation.
- Look up WWDC sessions or sample code.
- Check availability and platform constraints.

## Workflow

1. Search the relevant Apple framework or symbol.
2. Prefer official Apple docs and WWDC material.
3. Record platform availability and deprecations.
4. Apply findings to code with exact API names.

## Notes

Apple APIs change across OS releases. Verify current docs for version-sensitive work.
