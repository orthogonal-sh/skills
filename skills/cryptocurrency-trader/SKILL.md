# Cryptocurrency Trader

Use this skill when the user asks about crypto assets, markets, exchanges, trading setups, or portfolio monitoring.

## Workflow

1. Identify token, chain, exchange, time horizon, and whether the user wants research or trade planning.
2. Check price, liquidity, volume, funding, open interest, tokenomics, unlocks, and recent news.
3. Review on-chain activity, protocol health, governance, and security events where relevant.
4. Present scenarios, invalidation levels, and risk controls without overclaiming certainty.

## Notes

- Crypto data changes quickly; confirm timestamps.
- Warn about scams, thin liquidity, bridge risk, and contract risk.
