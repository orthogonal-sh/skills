# Web Deploy GitHub Pages

Use this skill when the user wants a simple static website published through GitHub Pages.

## When To Use

- Build a portfolio, landing page, documentation page, or one-page microsite.
- Add a GitHub Actions deployment workflow.
- Configure Pages for a branch or Actions build.
- Troubleshoot a failed Pages deployment.

## Workflow

1. Confirm the repo, base path, and custom domain needs.
2. Build the static assets.
3. Add or update the Pages workflow.
4. Push the branch and verify the deployment URL.

## Safety

Do not publish private or sensitive content. Confirm before changing DNS or custom domain settings.
