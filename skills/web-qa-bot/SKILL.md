# web-qa-bot

Use this skill when testing a website or web app for visible defects, broken flows, bad copy, responsive issues, dead links, or release readiness.

## Workflow

- Identify target URLs, key user journeys, supported viewports, auth needs, and acceptance criteria.
- Exercise navigation, forms, search, downloads, media, error states, and important CTAs.
- Capture evidence for failures with URLs, viewport, steps, screenshots, and console/network clues when available.
- Return prioritized findings and a quick pass/fail summary for launch readiness.
