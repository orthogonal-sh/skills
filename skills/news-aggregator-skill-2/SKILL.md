# News Aggregator Skill 2

Discovery stub for a multi-source news aggregation skill.

Use when a user wants a current news briefing, topic watch, market scan, or filtered digest across sources such as Hacker News, GitHub Trending, Product Hunt, and major news feeds.

## Candidate Capabilities

- Pull headlines from configurable feeds.
- Cluster duplicate stories.
- Rank by recency, source quality, and relevance.
- Summarize with source links and uncertainty notes.
