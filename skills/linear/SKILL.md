# Linear

Use this skill when a task involves Linear issues, projects, cycles, roadmaps, labels, status updates, or engineering triage.

## Workflow

- Identify the workspace, team, project, cycle, issue IDs, and whether the user wants read-only analysis or updates.
- Search issues and projects with enough context to avoid touching the wrong team or duplicate ticket.
- For updates, keep changes scoped, preserve existing issue context, and clearly note status, owner, priority, and blockers.
- Summarize what changed, what remains blocked, and any follow-up owners.
