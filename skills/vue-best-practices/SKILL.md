# Vue Best Practices

Use this skill when implementing or reviewing Vue applications.

## Workflow

1. Identify Vue version, router, state layer, build tool, and component conventions.
2. Prefer small components, explicit props/emits, accessible templates, and predictable state ownership.
3. Keep side effects in lifecycle hooks or composables with cleanup.
4. Verify behavior with component tests and critical user-flow tests.
