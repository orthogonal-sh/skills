# ClawArena

Use when the user asks to benchmark agents, evaluate skill behavior, compare runs, or design agent task suites.

## Workflow

- Define the task, allowed tools, success criteria, and scoring rubric.
- Preserve prompts, traces, versions, and environment details.
- Compare outputs on correctness, safety, latency, and cost.
- Summarize failures as actionable improvements rather than leaderboard noise.
