# CalDAV Calendar

Use this skill when working with calendars through CalDAV-compatible services.

## Workflow

- Identify the server, calendar collection, timezone, date range, and action requested.
- Read existing events before creating, editing, or deleting anything.
- Preserve UID, recurrence rules, attendees, alarms, and organizer metadata when modifying events.
- Confirm changes with exact dates, times, and calendar names.
