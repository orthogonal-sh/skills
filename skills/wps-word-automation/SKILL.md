# WPS Word Automation

Use this skill for single-document Word/WPS automation on Windows, including reading text, replacing content, inserting sections, managing headers, merging, splitting, and exporting.

## Notes

- Confirm the host is Windows with the required office application installed.
- Preserve the original document before destructive edits.
- Prefer deterministic operations over visual/manual document manipulation.
