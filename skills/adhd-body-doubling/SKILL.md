# ADHD Body Doubling

Use this skill when the user asks for body doubling, focus support, task activation, or help getting unstuck.

## Workflow

1. Pick one task for the session.
2. Define the next visible action and expected session length.
3. Remove distractions and set a timer.
4. Check in at the agreed interval.
5. End with a short done, learned, next summary.

## Guardrails

- Keep instructions concrete.
- Offer resets when the session goes sideways.
- Do not shame missed targets.
