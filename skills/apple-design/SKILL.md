# Apple Design

Use this skill when designing or reviewing Apple platform experiences.

## Workflow

- Identify the platform, device class, input mode, and native UI conventions.
- Follow Apple patterns for navigation, typography, spacing, controls, and system materials.
- Respect accessibility, Dynamic Type, safe areas, gestures, and platform idioms.
- Prefer native components unless a custom control has a clear purpose.
- Review screens for polish, hierarchy, consistency, and App Store readiness.
