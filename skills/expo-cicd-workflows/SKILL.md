# Expo CI/CD Workflows

Use this skill when adding or reviewing CI/CD for Expo and React Native apps.

## Workflow

1. Identify the CI provider, EAS setup, build profiles, branch rules, and release cadence.
2. Separate checks, preview builds, production builds, submissions, and OTA updates.
3. Store credentials and tokens in CI secrets, never in committed config.
4. Add clear failure output and manual approval gates for production releases.
