# Portainer

Use this skill when the user asks about Portainer, Docker stack management, container troubleshooting, or UI/API automation.

## Workflow

1. Identify the Portainer instance, environment, endpoint, and permission boundary.
2. Inspect stack, container, image, volume, network, and log state before changing anything.
3. Prefer non-destructive diagnostics and reversible changes.
4. Document applied changes and verification checks.

## Notes

- Ask before restarting, deleting, pruning, redeploying, or changing access control.
- Preserve compose files and environment variables.
