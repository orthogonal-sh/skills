# Things Mac

Use when a user wants to add, list, update, schedule, or complete tasks in Things 3 from macOS.

## Suggested Workflow

- Confirm task title, project, notes, tags, deadline, or reminder date when missing.
- Use local Things automation when available.
- Read before updating existing tasks so names and project placement are preserved.
- Report the created or updated task succinctly.

## Candidate Sources

- OpenClaw `things-mac`
- Things 3 URL scheme and local task database tooling
