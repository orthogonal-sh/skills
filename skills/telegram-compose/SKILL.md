# Telegram Compose

Use this skill when composing structured Telegram messages that need platform-aware formatting.

## Workflow

- Decide whether plain text or Telegram HTML formatting is appropriate.
- Keep messages mobile-friendly with short paragraphs and readable lists.
- Escape unsafe characters and validate links, mentions, and code snippets.
- Ask before sending unless the user explicitly requested delivery.
