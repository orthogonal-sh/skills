# Docker Essentials

Use this skill when working with Docker locally or in lightweight deployment workflows.

## Workflow

- Inspect Dockerfiles, Compose files, environment variables, ports, volumes, and existing containers.
- Prefer reproducible commands and minimal images that match the project's current patterns.
- Debug build failures, networking, permissions, health checks, logs, and resource usage.
- Clean up only targeted resources, and avoid destructive prune commands without explicit approval.
