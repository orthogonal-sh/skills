# Filesystem

Use this skill for file discovery, workspace cleanup, folder organization, file comparison, or safe local edits.

## Workflow

- Inspect current paths and git state before modifying anything.
- Prefer recoverable moves to permanent deletion.
- Use fast search tools for file and text discovery.
- Preserve unrelated user changes and avoid broad rewrites.
- Summarize important file paths and verification steps when finished.
