# Solana Dev

Use this skill when working on Solana smart contracts, Anchor projects, wallet integrations, transaction construction, RPC calls, token programs, or deployment/debug workflows.

Check network and cluster assumptions, keep key material out of logs, prefer localnet or devnet for tests, and verify account layouts, signer requirements, compute budgets, and transaction simulation output.
