# Reflect Notes

Use this skill when the user wants to capture, append, organize, or retrieve notes in a Reflect-like personal knowledge graph.

## Workflow

1. Determine whether the item is a thought, task, meeting note, source note, or durable memory.
2. Choose the right destination note, date, backlinks, and tags.
3. Preserve source context and timestamps.
4. Link related people, projects, decisions, and follow-ups.
5. Summarize long captures before saving them.

## Guidelines

- Search existing notes before creating duplicates.
- Keep task language actionable.
- Do not store secrets unless explicitly asked.
