# Remotion Best Practices

Use this skill when creating, reviewing, or refactoring Remotion video projects.

## Workflow

- Separate composition setup, scene logic, reusable components, and data.
- Make timing explicit with frames, sequences, and interpolation helpers.
- Keep assets deterministic and preloaded when needed for rendering.
- Check typography, safe areas, frame rate, duration, and resolution.
- Render or preview representative frames before handing off.
