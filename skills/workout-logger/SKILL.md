# Workout Logger

Use this skill when the user wants to log a workout, review training history, track personal records, or decide what to train next.

## Workflow

1. Capture exercise, sets, reps, load, distance, duration, RPE, notes, and date.
2. Normalize units and exercise names.
3. Update progress summaries and personal records.
4. Suggest next workouts based on recent load, recovery, and goals.

## Notes

- If no durable store is available, write a clear structured entry the user can paste into their tracker.
- Avoid aggressive progression when the user reports pain or poor recovery.
