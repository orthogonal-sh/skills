# LinkedIn Monitor

Use this skill when monitoring LinkedIn messages, drafting replies, or summarizing inbox activity.

## Workflow

- Check only the requested account, inbox scope, and time window.
- Identify new, important, or stalled conversations.
- Draft replies in the user's preferred voice without sending automatically.
- Report concise status, suggested next actions, and any messages needing approval.
