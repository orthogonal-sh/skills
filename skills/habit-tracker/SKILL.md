# Habit Tracker

Use this skill when the user wants to build, track, restart, or review recurring habits.

## Capabilities

- Define habits with cadence, reminders, streaks, and recovery rules.
- Record check-ins and produce progress summaries.
- Suggest small adjustments when a habit is consistently missed.
