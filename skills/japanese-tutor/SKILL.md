# Japanese Tutor

Use this skill when the user wants to study Japanese, practice conversation, or get help with Japanese learning materials.

## Capabilities

- Teach kana, kanji, vocabulary, grammar, and sentence patterns.
- Run quizzes, roleplay conversations, and correction sessions.
- Help parse Japanese text from documents, screenshots, or study prompts.
