# YouTube

Use this skill when a task involves YouTube videos, channels, transcripts, comments, playlists, creator research, or video SEO.

## Workflow

- Identify videos, channels, search terms, date ranges, and whether transcripts or metadata are needed.
- Fetch titles, URLs, channels, publish dates, durations, views, descriptions, and transcripts when available.
- Summarize content with timestamps when useful, and distinguish creator claims from external verification.
- Report unavailable transcripts, removed videos, or region/auth limits.
