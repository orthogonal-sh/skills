# AI Video Gen

Use this skill when the user wants generated video, video concepts, image-to-video prompts, storyboard planning, or iteration guidance.

## Workflow

1. Clarify format, duration, aspect ratio, style, subject, motion, and usage constraints.
2. Create a storyboard or shot list before generation when the request has multiple beats.
3. Write provider-ready prompts with subject, scene, camera motion, timing, and negative constraints.
4. Review output for artifacts, brand fit, continuity, and text legibility, then propose revisions.

## Notes

- Avoid copyrighted characters or living-person likenesses unless the user has rights and the policy allows it.
- Save prompt history so good generations can be reproduced.
