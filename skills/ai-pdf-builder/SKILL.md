# AI PDF Builder

Use this skill when a task involves producing or revising a PDF document, report, handout, worksheet, or designed export.

## Workflow

- Identify the source content, audience, page size, branding, layout constraints, and output requirements.
- Prefer structured intermediate formats such as Markdown, HTML, or templates.
- Check pagination, typography, image resolution, links, metadata, and accessibility basics.
- Export and verify the final PDF visually and with file-level inspection where appropriate.
