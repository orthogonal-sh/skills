# Serper

Use this skill when a task needs Google-style search results, news discovery, image search, places/maps lookup, or SERP enrichment.

## Workflow

- Translate the user request into focused search queries with time, site, entity, and geography filters as needed.
- Collect results with titles, snippets, URLs, publish dates, and result type, then remove irrelevant or duplicate hits.
- Prefer primary sources and recent authoritative pages for factual claims.
- Summarize findings with source links, confidence, and any search gaps.
