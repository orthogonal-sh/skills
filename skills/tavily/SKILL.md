# Tavily

Use this skill when Tavily is the preferred search or extract provider for web research.

## Workflow

- Form a narrow query and choose search depth based on the task.
- Filter domains, freshness, or source type when accuracy depends on it.
- Fetch full content for the most relevant results before synthesizing.
- Track source URLs, dates, and confidence.
- Fall back to another source if Tavily results are thin or stale.
