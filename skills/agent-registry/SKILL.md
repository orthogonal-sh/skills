# Agent Registry

Use this skill when a workspace has many agents, skills, or roles and the current task needs the right specialist.

## Capabilities

- Search agent and skill metadata before loading full instructions.
- Route work to the smallest suitable specialist context.
- Maintain a registry of capabilities, triggers, and handoff expectations.
