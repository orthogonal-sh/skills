# Exa Web Search Free

Use this skill when semantic web discovery is more useful than keyword search.

## Workflow

- Translate the user request into focused semantic queries and source-quality constraints.
- Search for primary sources, high-signal articles, documentation, datasets, or comparable examples.
- Deduplicate near-identical results and rank sources by authority, recency, and relevance.
- Summarize what each source contributes and call out gaps or low-confidence findings.
