# Anti UI Slop

Use this skill when a user asks for UI polish, design cleanup, frontend review, or help making an interface feel production-ready.

## Checklist

- Inspect the current UI and identify obvious issues in spacing, hierarchy, typography, contrast, states, and alignment.
- Prefer small, targeted changes that match the existing design system.
- Verify responsive behavior on mobile and desktop sizes.
- Check hover, focus, loading, empty, and error states when the surface includes interactions.
- Keep copy concise and avoid adding explanatory text inside the app unless the product needs it.
