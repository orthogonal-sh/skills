# Notion API

Use this skill when a task involves Notion databases, pages, blocks, properties, relations, rollups, or integration automation.

## Workflow

- Identify the workspace, integration permissions, target database or page, and intended read/write scope.
- Inspect schemas, property types, filters, sorts, pagination, and existing page structure before updates.
- Preserve user content and database conventions; avoid overwriting rich blocks or computed properties unintentionally.
- Verify writes by re-reading the changed page or database query result.
