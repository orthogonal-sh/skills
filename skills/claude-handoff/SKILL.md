# Claude Handoff

Use this skill when passing work to Claude, Claude Code, or a Claude-backed teammate.

## Workflow

- Summarize the objective, current state, and why the handoff is needed.
- Include relevant files, branches, commands already run, and test results.
- Preserve constraints, user preferences, and known pitfalls.
- State concrete next actions and expected output.
- Keep the handoff concise enough to paste directly into a fresh session.
