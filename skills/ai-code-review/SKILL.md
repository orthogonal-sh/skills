# AI Code Review

Use this skill when reviewing pull requests, commits, or diffs with an AI-assisted review flow.

## Capabilities

- Prioritize correctness, security, regression risk, and missing tests.
- Summarize large diffs into reviewable areas.
- Generate actionable findings with file and line references.
- Separate blocking issues from polish and follow-up suggestions.
