# nano-pdf

Use this skill when a user wants to modify a PDF by describing edits in natural language, especially for quick document cleanup, page operations, or text-oriented changes.

## Notes

- Confirm whether the PDF can be modified in place or should be copied first.
- Prefer explicit output filenames so the original document remains recoverable.
- Inspect the result after edits when visual fidelity matters.
