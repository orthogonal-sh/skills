# Code Explainer

Use when the user asks what code does, why it behaves a certain way, or how pieces of a codebase fit together.

## Workflow

- Read the relevant files before explaining.
- Start with the user-visible behavior, then trace implementation details.
- Cite file paths and line numbers for important claims.
- Call out uncertainty, side effects, and tests that would confirm the explanation.
