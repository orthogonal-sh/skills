# FFmpeg Video Editor

Use this skill when a task involves local video or audio transformation with ffmpeg.

## Workflow

- Inspect inputs with `ffprobe` before changing codecs, dimensions, duration, or streams.
- Choose commands that preserve quality when possible and re-encode only when needed.
- Handle trimming, concatenation, overlays, subtitles, audio normalization, thumbnails, and format conversion.
- Verify the output duration, streams, resolution, and playback before reporting completion.
