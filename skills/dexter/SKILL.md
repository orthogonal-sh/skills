# Dexter

Use when a user asks for investment-style research, company financials, market data, filings, or crypto fundamentals. This skill is for research support, not financial advice.

## Safety Rules

- Verify current prices, filings, and metrics from authoritative sources.
- Clearly separate facts from analysis and uncertainty.
- Avoid personalized investment recommendations unless the user has requested general educational framing.

## Candidate Sources

- OpenClaw `dexter`
- SEC EDGAR, company filings, market data APIs, and crypto data APIs
