# YouTube Transcript

Use this skill when a YouTube video should be summarized, mined for claims, turned into notes, or repurposed.

## Workflow

- Fetch transcript text and metadata, including title, channel, and publish date.
- Preserve timestamps for important claims, quotes, or chapter-like sections.
- Clean filler without changing meaning.
- Note when transcript quality, auto-captions, or missing segments limit confidence.
- Avoid long verbatim excerpts from copyrighted content.
