# sherpa-onnx TTS

Use this skill when a task involves local text-to-speech generation with sherpa-onnx, offline voices, audio exports, voice selection, or batch narration.

## Workflow

- Identify the text, voice/model, language, output format, sample rate, and target listening context.
- Split long scripts into natural segments and preserve ordering in filenames.
- Generate audio locally when privacy, latency, or offline operation matters.
- Verify output duration, intelligibility, clipping, and file format before handing off.
