# API Credentials Hygiene

Use this skill when integrating services, preparing deployments, or auditing how API credentials are stored and used.

## Stub Scope

- Map each credential to its service, scope, owner, environment, and rotation cadence.
- Move secrets out of code, logs, documentation, and screenshots.
- Provide redacted examples and placeholder commands instead of asking for keys.
