# OpenHue

Use this skill when a task involves Philips Hue or compatible smart lighting, scenes, rooms, device state, bridge pairing, schedules, or light automation debugging.

## Workflow

- Identify the bridge, rooms, lights, scenes, and whether the task should change physical devices.
- Read current state before applying scene, color, brightness, or schedule changes.
- Confirm before disruptive room-wide changes, nighttime lighting, or automation edits.
- Verify device state and report any unreachable bulbs, bridge errors, or partial updates.
