# Native App Performance

Use this skill when improving desktop or mobile native app performance.

## Capabilities

- Diagnose slow launch, hangs, jank, memory growth, and battery drain.
- Identify measurement tools and reproducible scenarios.
- Connect profiling evidence to code-level fixes.
- Define performance budgets and verification checks.
