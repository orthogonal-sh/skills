# SearXNG

Use this skill when a task should use metasearch while minimizing tracking or relying on a self-hosted search instance.

## Workflow

- Choose the SearXNG instance, enabled engines, language, date range, and safe-search settings.
- Query with focused terms and compare results across engines where useful.
- Filter out low-quality mirrors, scraped copies, and untrusted pages.
- Return concise findings with source URLs and known coverage limitations.
