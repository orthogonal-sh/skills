# Firebase Firestore Standard

Use this skill when working with Firebase Firestore in standard mode.

## Workflow

1. Model access patterns first, then collections, documents, indexes, and denormalization.
2. Review security rules alongside every query path and write operation.
3. Use transactions or batched writes where consistency matters.
4. Prefer emulator-backed tests for rules and critical query behavior.
