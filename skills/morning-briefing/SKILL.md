# Morning Briefing

Use this skill when a task asks for a morning briefing, daily plan, schedule preview, priority summary, or wake-up digest.

## Workflow

- Gather relevant calendar, reminders, urgent messages, weather, travel, project status, and user priorities for the day.
- Filter for what is actionable or time-sensitive, avoiding noisy low-value updates.
- Present the day in order: schedule, deadlines, risks, decisions needed, and helpful context.
- Note stale or unavailable sources so the user knows what was checked.
