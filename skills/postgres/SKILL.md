# Postgres

Use this skill when a task involves PostgreSQL databases, SQL queries, migrations, indexes, backups, performance, or connection/debugging work.

## Workflow

- Identify the database target, access method, environment, and whether the task is read-only or mutating.
- Inspect schema, constraints, indexes, query plans, and recent changes before proposing data or migration changes.
- Prefer safe, reversible operations; back up or stage destructive changes, and call out lock, downtime, and data-loss risks.
- Verify results with targeted queries, migration status checks, and application-level behavior where relevant.
