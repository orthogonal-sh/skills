# Clipit

Use when the user asks to inspect, transform, organize, or prepare clipboard content and snippets.

## Workflow

- Treat clipboard contents as private by default.
- Sanitize secrets before logging or sharing transformed text.
- Preserve original content until the user confirms replacements.
- Prefer local clipboard tools and reversible actions.
