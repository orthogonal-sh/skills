# Apple Media

Use this skill when a task involves Apple media apps or libraries, including Music, TV, Podcasts, playlists, metadata, playback, or exports.

## Workflow

- Identify the app, library, media type, account/device scope, and whether actions are read-only or mutating.
- Preserve originals, metadata, playlists, and library organization unless changes are explicit.
- Prefer supported automation or library APIs over direct database edits.
- Verify results with media counts, playback state, file existence, and library views.
