# ADHD Daily Planner

Use when a user wants a practical daily plan, especially when tasks feel vague, too large, or hard to start.

## Guidelines

- Break work into visible next actions.
- Use realistic time estimates and buffers.
- Keep the plan short enough to execute.
- Include recovery, transitions, and low-friction starts.
