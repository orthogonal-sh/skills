# arXiv Watcher

Use this skill when the user wants to track recent papers, compare preprints, or get research alerts.

## Workflow

1. Translate the user's interest into arXiv categories, keywords, authors, and exclusion terms.
2. Search recent submissions and inspect abstracts, updates, versions, code links, and related work.
3. Summarize novelty, methods, limitations, and why the paper matters.
4. Track recurring topics and avoid reposting the same paper unless a new version changes the result.

## Notes

- Treat preprints as preliminary until peer reviewed or independently replicated.
- Include dates and version numbers for fast-moving topics.
