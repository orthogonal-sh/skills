# Desktop Mouse

Use when the user needs desktop UI automation where browser or API automation is unavailable.

## Workflow

- Prefer accessibility selectors, app shortcuts, or APIs before raw coordinates.
- Capture the screen state before taking each irreversible action.
- Use small, verifiable steps with recovery points.
- Stop and ask before sending external messages, purchases, or destructive actions.
