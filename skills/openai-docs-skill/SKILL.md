# OpenAI Docs Skill

Use when a task involves OpenAI APIs, SDKs, models, platform features, migration guidance, or official implementation examples.

## Suggested Workflow

- Prefer official OpenAI documentation over third-party summaries.
- Check current model, endpoint, and SDK names before answering.
- Cite the relevant official docs in user-facing explanations when browsing is used.
- Distinguish stable API behavior from beta or preview features.
