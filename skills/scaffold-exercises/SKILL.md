# Scaffold Exercises

Use this skill when designing hands-on learning material or coding drills.

## Workflow

- Identify the learner level, target skill, and expected completion time.
- Create a starter state, clear goal, constraints, and success criteria.
- Add progressive hints and optional stretch goals.
- Include tests, review prompts, or an answer key when useful.
- Keep exercises focused on one concept unless the user asks for a curriculum.
