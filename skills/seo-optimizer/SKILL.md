# SEO Optimizer

Use this skill when the user asks for SEO audits, SEO fixes, metadata, schema markup, or search visibility improvements.

## Workflow

1. Inspect the target page, route, or site map.
2. Check titles, descriptions, headings, canonical URLs, robots rules, structured data, and internal links.
3. Prioritize fixes by likely search impact and implementation cost.
4. Verify the page still renders correctly after changes.

## Notes

- Keep recommendations tied to observable page content.
- Avoid keyword stuffing and thin content.
