# Gifgrep

Discovery stub for a GIF search and extraction skill.

Use when a user wants to find, download, trim, or inspect GIFs and short reaction clips from terminal workflows.

## Candidate Capabilities

- Search supported GIF providers.
- Download selected GIFs.
- Extract still frames or sheets.
- Return attribution and source metadata where available.
