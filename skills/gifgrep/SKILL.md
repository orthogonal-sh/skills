# gifgrep

Use this skill when a task involves finding moments inside GIFs or videos, extracting frames, creating short GIF clips, captioning, or checking animation timing.

## Workflow

- Identify the source media, target moment, output dimensions, frame rate, and file-size constraints.
- Use frame extraction or metadata inspection before re-encoding.
- Preserve an original copy and write derived clips to clearly named output files.
- Verify the resulting animation for timing, readability, looping, and size.
