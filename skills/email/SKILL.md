# Email

Use this skill for inbox triage, message search, drafting replies, follow-up tracking, or newsletter summaries.

## Workflow

- Search only the relevant mailbox, sender, date range, or thread when possible.
- Summarize important messages with sender, date, subject, and requested action.
- Draft replies in the user's style but ask before sending externally.
- Preserve thread context, attachments, and deadlines.
- Record durable follow-ups when a message implies future work.
