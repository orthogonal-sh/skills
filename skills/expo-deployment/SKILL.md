# Expo Deployment

Use this skill when preparing Expo or React Native apps for deployment.

## Workflow

1. Identify app ownership, EAS configuration, build profiles, runtime version, and update channels.
2. Check credentials, bundle identifiers, permissions, env vars, and store metadata.
3. Validate OTA update strategy, rollback plan, and release-channel separation.
4. Run the repo's build, lint, and smoke-test commands when available.
