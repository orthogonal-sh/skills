# Fastify Best Practices

Use this skill when working on Fastify applications, plugins, route handlers, validation schemas, lifecycle hooks, tests, observability, or production hardening.

## Workflow

1. Identify the Fastify version, plugin graph, route structure, and validation approach.
2. Prefer encapsulated plugins, explicit schemas, typed request/reply contracts, and small route modules.
3. Check async error handling, hook ordering, serialization, logging, and security headers.
4. Verify behavior with focused route tests and representative request payloads.
