# Guru MCP

Use this skill when a task involves a Guru knowledge base exposed through an MCP server.

## When To Use

- Search Guru cards.
- Ask a question over Guru knowledge.
- Create or update draft cards.
- Summarize internal documentation.

## Workflow

1. Connect to the Guru MCP server.
2. Search by exact terms first.
3. Inspect the most relevant cards.
4. Draft updates separately before publishing.

## Safety

Confirm before updating published knowledge base cards. Avoid exposing private internal content outside the approved audience.
