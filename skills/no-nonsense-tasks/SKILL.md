# No Nonsense Tasks

Use this skill when the user wants a local, straightforward task list without heavyweight project-management ceremony.

## Capabilities

- Add, update, complete, tag, and list tasks.
- Track backlog, todo, in-progress, blocked, and done states.
- Produce concise daily or project-specific task summaries.
