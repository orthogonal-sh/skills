# iOS Simulator

Use this skill when testing or automating iOS apps in Apple Simulator.

## Capabilities

- Boot, reset, and select simulator devices.
- Install, launch, terminate, and inspect apps.
- Capture screenshots, videos, logs, and crash reports.
- Manage permissions, locations, deep links, and test state.
