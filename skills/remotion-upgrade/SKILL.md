# Remotion Upgrade

Use this skill when a Remotion project needs a dependency or API upgrade.

## Workflow

- Check the current Remotion packages, Node version, bundler, and renderer setup.
- Read the relevant upgrade notes before changing code.
- Update package versions and migrate deprecated APIs in small steps.
- Run typecheck, previews, and representative renders.
- Record any behavior changes, render differences, or manual follow-ups.
