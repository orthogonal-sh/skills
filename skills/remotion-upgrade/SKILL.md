# Remotion Upgrade

Use this skill when upgrading a Remotion video project or diagnosing upgrade fallout.

## Workflow

1. Identify current Remotion packages, target version, renderer, bundler, and deployment path.
2. Read version-specific migration notes before editing code.
3. Update dependencies together and resolve API, codec, render, and config changes.
4. Render representative compositions and compare output duration, dimensions, audio, and visual state.
