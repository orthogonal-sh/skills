# Roadrunner

Use this skill when the user wants to interact with Beeper Desktop from the terminal.

## Workflow

1. Confirm the target chat or account from available context.
2. Search or list messages before sending anything externally.
3. Draft outbound messages and ask for confirmation unless the user explicitly instructed you to send.
4. Track followups or reminders when requested.

## Safety

- Private messages are external actions.
- Never send as the user without clear authorization.
