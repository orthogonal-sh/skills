# Topydo

Use this skill when the user wants todo.txt-compatible task management from the command line.

## Capabilities

- Add, list, complete, prioritize, tag, and search tasks.
- Manage projects, contexts, due dates, recurrence, and dependencies.
- Produce focused task views for today, this week, or a specific project.
