# UI Audit

Use this skill when reviewing screenshots, pages, prototypes, or frontend changes for user experience quality.

## Workflow

1. Inspect the interface in realistic desktop and mobile sizes.
2. Check hierarchy, spacing, contrast, keyboard access, focus states, labels, and text fit.
3. Prioritize issues by user impact.
4. Provide specific fixes tied to components or files.

## Notes

- Prefer concrete design changes over vague taste comments.
- Verify claims with screenshots or interaction checks when possible.
