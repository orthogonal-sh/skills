# Trakt

Use this skill when the user asks about movies, TV shows, watch history, watched status, or Trakt watchlists.

## Workflow

1. Authenticate through the configured Trakt app or token store.
2. Search shows, movies, seasons, episodes, people, or lists.
3. Read watch history, ratings, progress, and watchlists as requested.
4. Prepare updates for watched status, ratings, or list changes and ask before writing.

## Safety

- Do not mark media watched, rate items, or modify lists without confirmation.
- Keep tokens private.
