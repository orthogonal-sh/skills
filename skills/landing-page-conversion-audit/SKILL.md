# Landing Page Conversion Audit

Use this skill when reviewing a marketing page, homepage, signup page, or campaign landing page.

## Checklist

- Identify the target audience, offer, primary CTA, and conversion goal.
- Check first-viewport clarity, proof, objections, friction, and visual hierarchy.
- Review forms, pricing paths, mobile experience, and page speed risks.
- Verify analytics events for the main funnel steps.
- Return prioritized fixes with expected impact and effort.
