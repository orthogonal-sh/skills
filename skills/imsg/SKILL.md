# imsg

Use this skill when a task involves local iMessage search, conversation summaries, drafting replies, attachment lookup, or message workflow automation.

## Workflow

- Identify the contact, chat, date range, attachment needs, and whether the task is read-only.
- Treat sending, deleting, or editing messages as external actions requiring explicit confirmation.
- Preserve context around quoted messages so summaries do not misattribute speakers.
- Verify recipients, message text, and timestamps before any outbound action.
