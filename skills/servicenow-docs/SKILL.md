# ServiceNow Docs

Use this skill when a task involves ServiceNow platform behavior, APIs, release notes, or developer docs.

## When To Use

- Look up ServiceNow REST APIs.
- Verify table, workflow, or integration behavior.
- Find release-specific documentation.
- Summarize implementation guidance for admins or developers.

## Workflow

1. Search official ServiceNow docs first.
2. Note the product family and release.
3. Capture endpoint names, table names, and permissions.
4. Provide short examples without inventing undocumented behavior.

## Notes

ServiceNow behavior is release-sensitive. Always include the release when available.
