# qmd-2

Discovery stub for a local markdown knowledge search skill.

Use when a user needs to search notes, documentation, research folders, or markdown knowledge bases with keyword, vector, or hybrid retrieval.

## Candidate Capabilities

- Index markdown and plain-text knowledge directories.
- Search with BM25, semantic vectors, or hybrid ranking.
- Return cited snippets with source paths.
- Support local-first knowledge workflows without sending private docs to hosted search.
