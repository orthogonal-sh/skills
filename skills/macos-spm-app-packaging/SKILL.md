# macOS SPM App Packaging

Use this skill when packaging a Swift Package Manager macOS app for local install or distribution.

## Capabilities

- Build `.app` bundles from SPM targets.
- Configure Info.plist, icons, entitlements, and resources.
- Sign, notarize, staple, and verify release artifacts.
- Produce zips, DMGs, or updater-ready packages.
