# Architecture Designer

Use this skill for system design, architecture review, infrastructure planning, scalability tradeoffs, or architecture decision records.

## Stub Scope

- Start with constraints, users, failure modes, and operational requirements.
- Compare credible options with tradeoffs instead of defaulting to complex patterns.
- Record decisions with context, consequences, and rollback paths.

## Future Implementation Notes

- Add ADR templates and architecture review checklists.
- Add patterns for monoliths, services, eventing, queues, storage, and caching.
