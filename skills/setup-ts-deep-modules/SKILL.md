# Setup TS Deep Modules

Use this skill when organizing a TypeScript codebase into nested modules or packages.

## Workflow

- Inspect the existing package manager, tsconfig layout, bundler, and test runner.
- Choose path aliases, project references, or package boundaries that match the repo.
- Update imports, exports, and build scripts conservatively.
- Verify typecheck, tests, linting, and editor resolution.
- Document module ownership and import rules when the structure is non-obvious.
