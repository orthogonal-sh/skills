# Linear Autopilot

Use this skill when Linear issues should drive semi-automated coding, triage, or project execution workflows.

## Capabilities

- Convert Linear issue changes into agent tasks or notifications.
- Keep issue status, branches, commits, and PRs aligned.
- Report progress back to Linear and team channels.
