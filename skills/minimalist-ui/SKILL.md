# Minimalist UI

Use this skill when a user wants a simpler or more minimal product interface.

## Principles

- Remove low-value controls, labels, decoration, and repeated copy.
- Preserve the information needed for confident action.
- Use whitespace, alignment, and type weight for hierarchy.
- Keep affordances obvious even with restrained styling.
- Test empty, loading, focused, and disabled states.
