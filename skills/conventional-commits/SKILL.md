# Conventional Commits

Use this skill when writing commits, editing commit messages, or converting change summaries into commit titles.

## Stub Scope

- Use `<type>[optional scope]: <description>` with concise imperative descriptions.
- Choose types such as `feat`, `fix`, `docs`, `refactor`, `test`, `chore`, and `ci`.
- Include breaking-change footers when behavior or public APIs change incompatibly.
