# Ponytail Audit

Use this skill when a lightweight but structured audit is useful before shipping, refactoring, delegating, or escalating work.

Review the actual artifact, surface the highest-risk findings first, tie each finding to evidence, and finish with a short set of concrete fixes or verification steps.
