# Context7 Docs

Use this skill when implementing with an external library, framework, or SDK whose APIs may have changed.

## Workflow

1. Identify the exact package, version, framework, and language.
2. Query current documentation before coding against uncertain APIs.
3. Pull only the relevant sections, examples, and migration notes.
4. Apply the docs to the local codebase's existing patterns.
5. Cite or note the docs source in implementation summaries when useful.

## Triggers

- New framework usage.
- Version migration.
- API uncertainty.
- Errors that suggest outdated examples.
