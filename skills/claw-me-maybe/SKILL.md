# Claw Me Maybe

Use this skill when the user wants cross-platform messaging through Beeper.

## Workflow

1. Identify the exact contact, chat, and platform.
2. Read recent context before drafting a reply.
3. Ask for confirmation before sending unless the user explicitly authorized sending.
4. Report the message ID or chat reference after a send.

## Safety

- Treat all outbound messages as external actions.
- Do not reveal private user context in group chats.
