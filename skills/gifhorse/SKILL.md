# GifHorse

Use this skill when the user wants a reaction GIF, dialogue clip, subtitle GIF, or meme-like video excerpt.

## Workflow

1. Capture the source title, quote, character, mood, or target reaction.
2. Search the available clip index for matching scenes.
3. Select a short segment and caption style.
4. Render the GIF or video with readable timing and file size appropriate for the target platform.

## Safety

- Respect copyright constraints and keep clips short.
- Avoid offensive captions unless the user explicitly requests that tone.
