# Agent Pulse

Use this skill when supervising long-running agent tasks or summarizing agent health.

## Workflow

1. Gather active tasks, recent tool activity, pending waits, failures, and elapsed time.
2. Separate normal long-running work from blocked work, repeated errors, and missing permissions.
3. Produce concise progress, risk, and next-action summaries.
4. Avoid interrupting humans unless action is genuinely needed.
