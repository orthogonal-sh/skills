# Web Design Guidelines

Use this skill when designing, building, or reviewing websites and web apps.

## Checklist

- Put the primary user task in the first viewport.
- Make navigation predictable and content scannable.
- Use stable responsive layout constraints for repeated UI elements.
- Ensure text does not overflow, overlap, or become unreadable.
- Test keyboard focus, contrast, loading, empty, and error states.
