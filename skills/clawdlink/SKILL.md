# clawdlink

Use this skill when working with Clawdlink-style agent-to-agent messaging, relay setup, bridge scripts, friend requests, or remote task handoffs.

## Workflow

- Identify the local agent, target agent, relay path, identity, permissions, and intended message or task.
- Inspect bridge configuration, logs, request state, and delivery acknowledgements before retrying.
- Keep private context scoped to the intended recipient and avoid sending secrets through relays.
- Summarize delivery status, received replies, failures, and next troubleshooting steps.
