# Excel

Use this skill when a task involves `.xlsx` workbooks, spreadsheet analysis, formulas, cleanup, or report generation.

## Workflow

- Inspect workbook structure, sheet names, formulas, tables, and hidden rows or columns before editing.
- Use structured spreadsheet libraries instead of ad hoc text manipulation.
- Preserve formulas, formats, frozen panes, filters, and named ranges where possible.
- Validate totals, references, and sample rows after transformations.
- Export only the requested sheets or derived artifacts.
