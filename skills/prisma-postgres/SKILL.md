# Prisma Postgres

Use this skill when working on Prisma projects backed by PostgreSQL.

## Checklist

- Review models for correct relations, cascades, indexes, uniqueness, and nullable fields.
- Use PostgreSQL-native capabilities deliberately, including JSONB, enums, timestamps, and full-text search.
- Keep generated migrations small and readable.
- Validate query shape, transaction boundaries, and pagination behavior.
- Add tests for risky migration or query changes.
