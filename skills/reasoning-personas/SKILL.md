# Reasoning Personas

Use this skill when a problem benefits from multiple disciplined perspectives.

## Workflow

1. Pick relevant lenses such as builder, skeptic, operator, customer, security reviewer, or investor.
2. Have each lens produce concise observations.
3. Compare tensions and shared conclusions.
4. Synthesize a practical recommendation.
5. Note which lens changed the decision.

## Good Fits

- Product strategy.
- Architecture review.
- Risk analysis.
- Naming and positioning.
- Postmortems.
