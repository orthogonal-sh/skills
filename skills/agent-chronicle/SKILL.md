# Agent Chronicle

Use this skill when a user asks for agent journaling, diary entries, self-reflection, or durable notes from the agent's point of view.

## Stub Scope

- Capture what happened, what was learned, and what should change next time.
- Keep private user details out of reflective summaries unless the user explicitly asks to remember them.
- Distinguish raw daily notes from long-term curated memory.

## Future Implementation Notes

- Add templates for daily entries, weekly reviews, and incident reflections.
