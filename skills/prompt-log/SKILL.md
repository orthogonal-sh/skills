# Prompt Log

Use this skill when a user asks to export, inspect, summarize, or preserve prompts and replies from local Clawdbot, Claude Code, or Codex session logs.

## Notes

- Treat session logs as private by default.
- Redact secrets and unrelated personal context before sharing excerpts.
- Preserve source paths and timestamps for traceability.
