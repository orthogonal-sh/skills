# Ponytail Debt

Use this skill when evaluating cleanup work, deferred refactors, brittle systems, duplicated logic, or messy operational processes.

Separate annoying debt from costly debt, estimate blast radius, propose small reversible cleanup steps, and connect each recommendation to developer speed, reliability, or user impact.
