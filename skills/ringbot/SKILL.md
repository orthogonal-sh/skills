# RingBot

Use this skill when the user asks to make or manage phone calls through RingBot.

## Workflow

1. Confirm the phone number, purpose, desired outcome, and caller identity.
2. Draft a short call script before initiating the call.
3. Capture transcript, outcome, callback needs, and followup tasks.
4. Report concise results to the user.

## Safety

- Ask before initiating any outbound call.
- Do not impersonate the user unless explicitly instructed.
