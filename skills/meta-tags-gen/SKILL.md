# Meta Tags Gen

Use this skill when improving page metadata for SEO and social sharing.

## Workflow

- Inspect existing title, description, canonical, Open Graph, and Twitter Card tags.
- Generate concise metadata that matches page intent and avoids keyword stuffing.
- Include image, URL, and structured-data recommendations when relevant.
- Verify tags render correctly in the target framework or static HTML.
