# Discord Voice

Use this skill when working with Discord voice channels, voice bot setup, real-time conversation, or audio session debugging.

## Workflow

- Confirm the Discord server, voice channel, bot permissions, and audio route.
- Join or monitor the voice session only when explicitly requested.
- Handle speech-to-text, response generation, and text-to-speech boundaries carefully.
- Troubleshoot gateway, codec, permissions, and connection failures with concise diagnostics.
