# LLMWhisperer

Use this skill when extracting structured text from PDFs, scans, forms, or visually complex documents.

## Capabilities

- Extract OCR text while preserving reading order and layout.
- Pull tables, key-value fields, and section structure.
- Prepare document chunks for downstream LLM analysis.
- Compare extraction quality against source pages.
