# LLMWhisperer

Use this skill when extracting text, tables, layout, or handwriting from PDFs and images.

## Workflow

- Identify document type, pages, required fields, and desired output format.
- Use LLMWhisperer extraction for OCR and layout-sensitive parsing.
- Validate tables, form fields, handwriting, and low-confidence regions.
- Return structured data plus notes about uncertain or unreadable content.
