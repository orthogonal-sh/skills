# BlueBubbles

Use this skill when a task involves the BlueBubbles iMessage bridge, remote iMessage access, chat search, attachments, send workflows, or bridge diagnostics.

## Workflow

- Identify the BlueBubbles server, target chat, contact, date range, and requested action.
- Inspect sync and connection state before relying on message history or sending.
- Require confirmation for outbound messages or chat-state changes.
- Verify message IDs, recipients, attachments, and bridge response after any confirmed action.
