# Session Logs

Use this skill when a task involves locating agent session logs, reading transcripts, reconstructing prior tool actions, debugging failures, or summarizing session history.

## Workflow

- Identify the relevant agent, workspace, date range, session ID, and failure or decision being investigated.
- Prefer indexed or structured log metadata before opening large raw transcripts.
- Quote or summarize only the portions needed for the task, preserving privacy boundaries.
- Report concrete timestamps, commands, files, and outcomes when reconstructing events.
