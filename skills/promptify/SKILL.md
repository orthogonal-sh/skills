# Promptify

Discovery stub for a prompt optimization skill.

Use when a user asks to improve, debug, simplify, or harden a prompt for an agent, LLM, workflow, or automation.

## Candidate Capabilities

- Clarify goals, context, constraints, and output shape.
- Identify ambiguity and hidden assumptions.
- Produce prompt variants for different models or surfaces.
- Add evaluation criteria for repeated use.
