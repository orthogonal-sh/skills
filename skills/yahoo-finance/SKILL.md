# Yahoo Finance

Use this skill when the user asks for market data or company finance context that Yahoo Finance can provide.

## Workflow

1. Confirm ticker and region.
2. Pull quote, chart, profile, financials, options, holders, and news data as needed.
3. Cross-check unusual values with another source.
4. Report timestamps, currency, exchange, and whether data is delayed.

## Notes

- Yahoo Finance endpoints and page markup can change; verify results before relying on automation.
- Do not scrape aggressively.
