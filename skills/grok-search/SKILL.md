# Grok Search

Use this skill when the user wants current web or X search through xAI Grok.

## Workflow

1. Choose web search or X search based on the question.
2. Use focused queries with date or account filters when needed.
3. Compare multiple results before answering.
4. Include citations or source links when reporting findings.

## Safety

- Treat social search results as noisy until corroborated.
- Avoid quoting private or deleted content.
