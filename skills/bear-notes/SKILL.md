# Bear Notes

Use this skill when a user wants to work with Bear notes from the terminal, including search, creation, tagging, and note updates.

## Notes

- Read existing notes before appending or rewriting.
- Preserve user-authored formatting and tags.
- Ask before deleting or bulk-moving notes.
