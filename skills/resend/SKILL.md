# Resend

Use this skill when a task involves Resend email sending, domains, DNS setup, deliverability, audiences, templates, or webhook debugging.

## Workflow

- Identify the sender domain, environment, recipient scope, template, and whether the email should actually be sent.
- Check DNS, sender verification, API credentials, payload fields, and rate or compliance constraints before sending.
- Treat external email sends as user-visible actions; draft or test first unless sending is clearly authorized.
- Verify message delivery, bounce/complaint state, webhook events, and application logs.
