# Documenting Contracts

Use this skill when documenting an interface that another team, system, agent, or customer needs to call or depend on.

Describe inputs, outputs, auth, errors, pagination, idempotency, versioning, rate limits, examples, and compatibility guarantees from the caller's point of view.
