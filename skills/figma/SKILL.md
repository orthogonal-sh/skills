# Figma

Use this skill when the user asks to inspect, translate, or implement Figma design work.

## Workflow

- Confirm the target frame, design version, and implementation surface.
- Extract layout, typography, color, spacing, component states, and assets.
- Map design tokens and components to the existing codebase.
- Flag missing assets, ambiguous states, and responsive gaps.
- Produce implementation notes or code with clear design-to-code traceability.
