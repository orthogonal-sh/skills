# Hyperframes Creative

Use this skill when a user needs creative direction for AI-generated video, campaign visuals, product storytelling, or concept variants.

## Workflow

- Identify the message, audience, brand constraints, and distribution channel.
- Produce a concise concept with scenes, mood, references, and prompt language.
- Create a small set of distinct variants rather than tiny prompt tweaks.
- Favor concrete visual details over abstract adjectives.
- Review outputs for brand fit, continuity, and usability.
