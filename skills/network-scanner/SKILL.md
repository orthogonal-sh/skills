# Network Scanner

Use this skill when diagnosing local network devices, connectivity, open ports, or unknown hosts.

## Workflow

1. Confirm the allowed network range and scan purpose.
2. Discover live hosts and basic metadata.
3. Inspect relevant ports and services conservatively.
4. Map hostnames, MAC vendors, and likely device roles.
5. Report findings and recommended fixes.

## Safety

- Only scan networks the user owns or is authorized to test.
- Avoid aggressive scans unless explicitly approved.
- Do not exploit discovered services.
