# Design Doc Mermaid

Use this skill when drafting technical design documents that benefit from diagrams.

## Workflow

1. Identify the system boundary, actors, data flow, state transitions, and deployment shape.
2. Choose the simplest Mermaid diagram type that clarifies the design.
3. Pair diagrams with concise prose covering constraints, alternatives, risks, and rollout.
4. Validate diagrams render and keep labels short enough to scan.
