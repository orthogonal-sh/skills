# n8n Workflow Automation

Use this skill when a task involves building or troubleshooting n8n automations.

## Workflow

- Map the trigger, input schema, transformations, side effects, credentials, and failure paths.
- Inspect workflow JSON, execution logs, node settings, and rate limits before changing behavior.
- Prefer idempotent, retry-safe designs with clear error handling and observability.
- Document setup requirements, secrets, test cases, and expected outputs.
