# MCP Skill

Use this skill when working with MCP servers or connecting tools to MCP-capable clients.

## Workflow

- Identify the transport, server command, authentication model, and client target.
- Inspect available tools, resources, schemas, and example calls before making changes.
- Validate tool inputs and outputs with simple calls before deeper integration.
- Document setup, environment variables, permissions, and failure recovery.
- Keep server capabilities narrow and predictable for agent use.
