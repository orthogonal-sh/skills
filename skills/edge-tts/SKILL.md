# Edge TTS

Use this skill when a user wants spoken audio from text with controllable voice, speed, pitch, and subtitle output.

## Notes

- Choose a voice appropriate to the language and context.
- Save generated audio with descriptive filenames.
- Include subtitles or timestamps when the audio will be reviewed or repurposed.
