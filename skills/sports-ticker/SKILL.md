# sports-ticker

Use this skill when the user wants a sports update, team watchlist, daily slate, standings check, matchup context, or score alert.

## Workflow

- Confirm sport, league, team, date range, timezone, and whether live or historical data is needed.
- Prefer authoritative league, team, or supported sports data sources for scores and schedules.
- Separate confirmed results from previews, projections, injuries, and odds context.
- Return a compact update with times, opponents, venue, broadcast notes when relevant, and source freshness.
