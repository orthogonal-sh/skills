# Table Image

Use this skill when tabular data needs to be shared as an image for messaging apps, reports, or compact visual summaries.

## Workflow

- Normalize the table data, headings, alignment, and important highlights.
- Choose a readable layout, font size, and width for the target platform.
- Render the table to an image and verify long text does not overflow.
- Provide the image plus a short plain-text summary when useful.
