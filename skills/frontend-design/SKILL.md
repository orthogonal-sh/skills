# Frontend Design

Use this skill when implementing or reviewing user-facing frontend screens.

## Checklist

- Match the existing design system, component patterns, and product density.
- Use clear hierarchy, consistent spacing, readable type, and restrained color.
- Include expected interaction states, empty states, and error states.
- Ensure layout works at mobile, tablet, and desktop widths.
- Verify behavior with screenshots or integration tests when possible.
