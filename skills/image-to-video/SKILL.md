# Image To Video

Use this skill when a user wants to animate a still image, create a product motion clip, generate B-roll from an image, or make short visual variants.

## Workflow

- Inspect the source image and preserve important subject details.
- Describe camera movement, subject motion, atmosphere, and what must stay unchanged.
- Generate short clips before longer variants.
- Verify framing, subject consistency, artifacts, duration, and aspect ratio.
- Save outputs with descriptive names and note the prompt used.
