# Verify On Browser

Discovery stub for a browser verification skill using Chrome DevTools Protocol.

Use when a user needs a page, UI change, or web workflow verified through browser state instead of static code inspection.

## Candidate Capabilities

- Connect to a CDP-enabled browser.
- Inspect DOM, network, console, and screenshots.
- Verify interactions and rendered state.
- Produce concise evidence for UI or automation checks.
