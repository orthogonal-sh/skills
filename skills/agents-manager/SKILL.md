# Agents Manager

Use this skill when the user wants to list agents, route work, compare capabilities, or coordinate agent handoffs.

## Workflow

1. Inventory available agents and their current status.
2. Match the task to agent capabilities, access, cost, and risk.
3. Send compact instructions with clear deliverables and constraints.
4. Merge returned work and note any assumptions.

## Safety

- Do not share private context unless it is required for the delegated task.
- Keep one owner responsible for final quality.
