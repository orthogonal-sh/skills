# Coding Agent

Use this skill for software-engineering tasks where an agent should inspect a repo, make changes, verify them, and report back.

## Workflow

- Start by reading repo structure, instructions, and relevant code.
- Keep edits scoped to the user's request and existing project patterns.
- Preserve unrelated worktree changes.
- Run the most relevant formatting, tests, or checks available.
- Report changed files, verification results, and any residual risks.
