# Apple Music

Use this skill when a task involves Apple Music playlists, library metadata, playback, recommendations, exports, or automation.

## Workflow

- Identify the account/library scope, playlist, track, artist, device, and whether changes are mutating.
- Prefer read-only inspection before playlist edits, deletes, or playback control.
- Preserve metadata and playlist ordering unless the task explicitly changes them.
- Verify changes with track counts, playlist membership, and playback or library state where available.
