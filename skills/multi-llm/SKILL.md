# Multi-LLM

Use this skill when a task benefits from model selection, fallback routing, or comparison across LLM providers.

## Capabilities

- Match tasks to models based on reasoning, coding, vision, speed, and budget.
- Fall back gracefully when a provider fails or rate limits.
- Compare model outputs for high-stakes or ambiguous decisions.
