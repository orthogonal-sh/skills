# Ask Questions If Underspecified

Use this skill when a request cannot be completed responsibly because key requirements are missing.

## Workflow

1. State what is known and what decision is blocked.
2. Identify the smallest set of missing facts.
3. Ask one to three specific questions.
4. Offer a sensible default when available.
5. Proceed once the user answers or accepts the default.

## Principles

- Do not ask questions for information you can inspect yourself.
- Keep questions short.
- Avoid blocking on preferences that can be safely inferred.
