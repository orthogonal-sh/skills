# Codex CLI

Use this skill when delegating implementation, code review, test writing, or repo exploration to the Codex CLI.

## Workflow

1. Give Codex a narrow task, repository path, and expected output.
2. Prefer isolated branches or worktrees for larger changes.
3. Monitor progress and collect diffs, tests, and notes before merging results.
4. Review generated changes before presenting them as complete.

## Safety

- Do not delegate secrets or private unrelated context.
- Do not accept generated changes without verification.
